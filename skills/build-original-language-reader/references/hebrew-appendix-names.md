# 希伯來專名附錄：分節、去重與世系

owner 2026-08-29 指出三件事，三件都成立，也都修了。修法與踩到的坑寫在這裡，
因為每一個都是「印出來才看得出來」的那種。

## 分節就是標籤，一個名字只出現在一節裡

人名分四類（owner 定）：**先祖與族長／君王／先知／新約門徒**，其餘歸其他人名；
地名與民族國名照舊。原本卡上印的是 `properNameTypes`——那是 Strong's 提到的
所有身分的清單，所以以色列印成「人名、民族／國名」、但印成「人名、地名」。
清單當證據留在資料裡，**印出來的只能有一個**，取分節名。

分節現況（`appendix-tables.json` 的 `hbo-appendix-proper-names`）：

    民族與國名 12｜地名 27｜神名與稱號 8｜君王 6｜其他人名 49｜先祖與族長 34｜先知 6

舊的「族長與先知」拆成兩節。留在裡面的約書亞（領袖）與約伯（受苦的義人）都不是
族長也不是先知，歸其他人名——這是判斷不是規則，所以逐個寫在
`scripts/fix_hebrew_proper_names.py` 的 ANCESTORS／KINGS／PROPHETS 三個集合裡。

## 重複有三種，只抓一種是抓不完的

1. **同一節裡出現兩次**：耶和華、神、巴力、約拿單。
2. **字形不同但印出來一樣**：耶路撒冷有 ketiv／qere 兩種寫法，附點不同、
   卡面完全相同。只比附點抓不到，要同時比**印出來的名字**。
3. **跨表重複**：安息日在曆法表已經有一張卡，專名表的「節期與聖日」又出一張。
   節期歸曆法表，專名表那一節清空。

## 名字與說明要分欄

中文欄原本寫成一整句描述——「以實瑪利；亞伯拉罕長子及五名以色列人的名字」——
印在卡上會被字級階梯縮到看不清，而且讓「同一個名字出現兩次」看不出來。
現在 `name` 只放「；」之前那一段，其餘進 `nameNote`。

順帶抓到一筆錯名：「有福的」是 אָשֵׁר 的字義，那個人叫**亞設**。第一次用
「取第一段」的規則反而把字義當成了名字——規則對多數列有效不代表對每一列都有效。

## 補上的創世記世系

亞當、塞特、以諾、瑪土撒拉、撒拉、夏甲、基土拉、利百加、利亞、悉帕、辟拉、
以薩迦（其餘 20 位原本就在表裡，只是中文欄寫成描述）。

- **附點取自創世記本文**（OSHB），不取字典的引用式——本讀本的規矩是名字以
  聖經最早出現處的寫法為準；重音記號（טעמים）去掉，那些屬於那一節經文。
- Strong 編號逐個以信望愛字典的釋義核對過。用中文名去比對釋義文字是**行不通**
  的：撒拉會命中 H00028 אֲבִידָע，因為那條釋義裡提到撒拉。看起來像找到，其實是
  另一個人。
- 「流便」不要改：這一份的中文用《和合本修訂版》，那裡作**呂便**。

## 兩個會讓修改完全無效的陷阱

1. **修在錯的檔上。** `data/originalReaders/vocabulary/hebrew-proper-names.json`
   是詞表；**印出來的附錄卡與網頁附錄表讀的是**
   `output/source-cache/original-readers/hebrew-full/appendix-tables.json`。
   第一輪只改了前者，卡片一張也沒變。
2. **分節 id 要用中文類名**（民族與國名、地名…）。新開的節若給英文 id，
   id 一半中文一半英文，靠 id 找節的程式就會找不到。

## 母音檢查的例外

`isFullyPointedHebrewWord` 擋下了 יִשָּׂשכָר——它擋得對，那個字中間的 שׂ 確實
沒有母音。但那是這個名字有名的怪拼法（第二個 שׂ 不發音），照經文抄下來就長這樣。
要求它比馬所拉本更整齊是錯的方向，所以列為輔音骨架例外並寫明理由。
