# 一課十題翻譯練習

2026-09-11 由擁有者定案，四本讀本共用。這一層取代原本每課兩節背誦經文的位置：
詞表 → 讀物 → **練習十題**。

## 定案的規格

| 項目 | 定案 |
| --- | --- |
| 方向 | **只做原文 → 繁體中文**。不做中文 → 原文（自學無人批改，回譯沒有唯一答案） |
| 題數 | 每課十題 |
| 組成 | **七題自撰 ＋ 三題經典原句**。原句是定錨：學習者永遠有正確樣本可對照 |
| 覆蓋 | 本課二十詞**全部**要出現，重複出現沒關係 |
| 生字 | **零**。題目中每個詞都必須是本課或先前課次教過的。不用腳註補生字 |
| 長度 | 三到八個詞，短句優先；課次越前面越短 |
| 語域 | 只能用經典本身的詞與世界觀，不得出現該經典世界以外的事物 |
| 中文 | **練習題不印中文**（2026-09-11 擁有者改定）。題目的目的就是讓學習者自己翻，中譯只有「範文」也就是每課讀物才給。原先「引用題取既有譯本」那條作廢 |
| 湊不滿 | 定錨不足三題時**用自撰題補滿十題**，該課註明「本課無可用經典原句」，不視為失敗 |

自撰為主是擁有者的決定，理由是純引用填不滿生字表：實測希伯來全五十課，
純原句只能覆蓋 71.6%，且第 1、2、3、4、7 課連十題都湊不滿。
拉丁上冊第 1 課更極端：二十詞裡只有 `flectō` 一個動詞，整部武加大挖不出一句三到八詞、每個詞都已教過又有謂語的句子，所以那一課定錨掛零。

## 三種出題法，只有兩種可用

**一、引用**（`kind: "quoted"`）。從語料挖出「全句每個詞都已教過」的整節或依原文
自己的停頓切出的子句。可靠度滿分：句子是經文，中文是既有譯本。
希伯來走 `scripts/build_hebrew_exercises.py`，拉丁走 `scripts/build_latin_exercises.py`
（`--volume 1` 挖武加大、`--volume 2` 挖下冊教會讀物）。

**二、自撰**（`kind: "composed"`）。作者寫句子，語料驗句。這是主力。

**三、機械替換——已驗證不可用，不要再試。** 拿原句當骨架、把某個詞換成形態標記
完全相同的另一個詞，產出的是詞沙拉：

> `וְחַי מֵאֶרֶץ שְׁכַב אָב יִפְקֹד שָׁנָה`

每個詞形都是真的、標記全對，句子不成話。句法不在形態標記裡。同類的失敗還有
同源賓語句式——`אַךְ נִגּוֹף נִגָּף הוּא` 的不定詞絕對式必須與主要動詞同字根，換成
`הִפָּקֵד נִכְבָּד` 標記依然全對而句式已壞。

## 機器閘擋得住什麼、擋不住什麼

`scripts/compose_hebrew_sentences.py --check` 是希伯來的閘，其餘語言照樣造。

**擋得住**（三條，全部是機械判定）：

1. 每個詞形必須在權威語料中實際出現過，同樣的子音與母音——捏造的變化形一律退回
2. 每個詞必須已教過——用未教的詞一律退回
3. 十題合起來必須涵蓋本課二十詞

**擋不住**：句法與母音點。實測 Haiku 寫的十句有八句過閘，其中三句仍有真錯
（`בַּיּוֹם הַשַּׁבָּת` 兩個冠詞疊、`וַחָזַק` 連接詞形錯、`שִׁמוֹ` 母音點錯）。
**過閘不等於正確**，自撰題一律要作者逐句複核。

「相鄰兩詞必須在語料中連用過」這道閘測過了，太稀疏不能用：`הכהן+מצא`
（祭司找到）這種完全正確的組合也會被判不合格。

### 日文對三道閘的兩條調整（2026-09-11，實作在上面三支腳本裡）

1. **第一道閘查基本形，不查表層形。** 希伯來要求寫出來的那個形連母音點都在 WLC
   出現過，因為希伯來的變化形不規則、捏一個看不出破綻。日語活用是規則的，
   讀む→読みます→読んで 推得出來，而語料再大也收不齊每個詞的每個活用形；照希伯來
   辦，「本を読みます」會因為語料只出現過「読んだ」被退回，正確的句子整批誤判。
   表層形沒見過仍會算，只印在 `unseenForms` 供作者參考，不構成退回。
   另外**課本收了而語料沒收的詞算數**（朝ご飯：戰前作家寫朝飯／朝御飯）——這一閘
   擋的是憑空造的詞，不是用字習慣的差異。
2. **助詞助動詞是文法不是生詞**，比對的是讀本自己的封閉詞類表
   （`build_japanese_interlinear.py` 的 `CLOSED_CLASS`，即附錄二那張表），
   不在表上的才算未教過。🚨 助詞不可拿去查那張 2,000 詞的詞表：詞表裡
   「は」是歯、「や」是屋，照假名比中全書每個主題助詞都會印成「牙齒」。
   兩個字以上的形式（ある、という、ながら）要能回退查表，否則上千處空掉。
   課本的多詞素詞條（一緒に、いつも、それから、サッカーを します）要整串比對，
   逐個 token 查一定判成未教過。

### 日文的兩條 owner 裁定（2026-09-11）

1. **練習題不附中文。** 練習題就是要學習者自己翻譯，題目只印日文原文；中文只有
   每課的**範文（讀物）**才需要。上表「中文」那一列（引用題取既有譯本）對日文
   不適用，`chinese` 與 `chineseSource` 留空即是完成狀態。
   `validate_reader_exercises.py` 已於同日改完：中文欄**有東西才會被退回**
   （等於把答案印在題目旁邊），`chineseSource` 不再必填，引用題改看 `answerKeyRef`。
2. **定錨不足時用自撰題補滿十題**，該課註明「本課無可用經典原句」，不放寬詞表
   限制硬湊。文語那半（第三、四冊）因此是自撰題為主——它的語料（文語訳聖書、
   萬葉集）用詞幾乎都不在《大家的日本語》的現代語詞表裡，只供得出 17 句與 3 句。

## 產物 schema

```json
{
  "schemaVersion": "1.0.0",
  "languageCode": "hbo",
  "direction": "original-to-chinese",
  "itemsPerLesson": 10,
  "lessons": [{
    "lesson": 13,
    "items": [{
      "no": 1,
      "kind": "quoted",
      "ref": "Gen.18.21",
      "text": "…",
      "answerKeyRef": "Gen.18.21",
      "targetWords": [{"pointed": "…", "strongs": ["H…"]}],
      "verification": {"unattested": [], "untaught": [], "passed": true},
      "reviewedBy": "author"
    }],
    "coverage": {"lessonWords": 20, "practised": 20, "notPractised": []}
  }]
}
```

`kind: "quoted"` 必附 `ref`；`kind: "composed"` 的 `reviewedBy` 必須是 `author`——
模型寫的草稿沒有作者逐句看過，不得標成已複核。

`chinese`／`chineseSource` 自 2026-09-11 起**不再是必填**，題目也不印。
引用題改記 `answerKeyRef`（出處精確到節或段），將來若要編書末解答本，
拿這個去抓既有譯本即可；記出處而不記譯文，也保證這一層不會把某個版本的
中文漏進一頁本來就該空白的練習。

## 驗證閘

`scripts/validate_reader_exercises.py` 對每一本跑，全綠才可進版面：

- 每課恰十題
- 每課 `quoted` 至少三題，且每題有 `ref`
- 二十詞全覆蓋，`notPractised` 必須是空的
- 每題 `verification.passed` 為真
- 每題 `unattested` 與 `untaught` 都是空的
- `composed` 題的 `reviewedBy` 必須是 `author`
- 中文欄**必須是空的**——練習題印了中文等於把答案印在題目旁邊
  （2026-09-11 反轉：舊規則是「不得為空」）
- 定錨少於三題時，該課 `note` 必須說明原因；湊不滿本身不算失敗，不吭聲才算

## 已知的坑

- **maqqef 連寫**：`אֶת־הָאָדָם` 是兩個詞寫在一起。驗證前不先拆，整串查不到，
  會把正確的句子整批誤判。希臘的 crasis 同理。
- **拉丁附著詞要反過來防「假拆」**：`armaque` ＝ `arma` ＋ `que`，但 `itaque`
  不是 `ita` ＋ `que`；`neque`、`quisque`、`namque`、`denique`、`atque`、`utique`
  也都不是。字尾一模一樣，只能問詞典：**整個形本身就在詞表裡就絕不拆**。
  `-ne`／`-ve` 的誤拆風險更高（`bene`、`omne`、`sive`、`nomine`）。
  拆開之後**主詞與附著詞要各自過「已教過」那一關**——`-que` 第一課就教了，
  兩半併在一起判的話，任何名詞黏上 que 都會從第一課起全部過關。
- **拉丁正字法只能用於比對**：`cælum`／`caelum`、`ejus`／`eius`、`uidit`／`vidit`
  是同一個詞，比對前要折疊；但**印出來必須是原樣**，折疊過的字不得進版面。
- **片語詞條不能被其中一個詞記成已練**：`in saecula`、`grātiās agere` 若可由
  單一個 `in` 記帳，二十詞涵蓋這道閘就形同虛設。片語要整組到齊才算。
- **同形異詞**：撒上 4:18 的 `וְכָבֵד` 是形容詞 H3515，與第 13 課要練的動詞
  `כָּבֵד` H3513 不是同一個詞。用字形比對會放過，用 Strong 比對才擋得下。
- **拉丁版同形異詞會從「涵蓋」那一頭漏**：沒有 Strong 碼，詞位只能查形表，
  而一個字形常掛兩個詞位——`missa` 既是彌撒也是 `mitto` 的陰性完成分詞，
  於是 `et misit in terram`（他差遣到地上）把「彌撒」記成練到了；`festum`
  被人名 `Festus`（非斯都）記到，`praeceptum` 被動詞 `praecipio` 記到，
  `nōn` 被 `nonnullus` 記到。三道閘全綠，錯的是帳。判準：**詞位折疊後必須
  等於詞條 headword 本身**才算練到；派生、詞源、專名一律不算，但
  `Angelus`→`angelus`、`Dominus`→`dominus` 這種大小寫變體要留。
  實測上冊「練到的詞次」因此從 535 降到 417，降的全是本來就不該算的。
- **詞表的文法縮寫別當成詞**：`ēlēctus, -a, -um` 的 `-a`、`liturgia,
  liturgiae, f.` 的 `f.` 若進了比對鍵，`contrītus` 會解到 `ad`／`hic`、
  `liturgia` 會解到一個叫 `f` 的詞位。開頭是連字號的是字尾，
  `forms` 欄裡的單字母是縮寫，兩種都不是詞。
- **引擎吐不出 JSON**：NVIDIA 那層對這類要結構化輸出的任務回的是推理散文，
  `--engine auto` 常拿到 0 句。要結構化輸出時明確指定引擎。
- **重音符號不可搬家**：馬所拉重音標的是該詞在**它自己那一節**裡的位置，
  搬到別句就是偽造。自撰題一律不標重音，只留母音點。

## 版面：怎麼接、接在哪裡

希伯來已接完（2026-09-12），紙本與線上都看得到。三件事照抄即可：

**一、跨檔的鍵是詞序號，不是課次編號。** 練習檔自己帶 `lesson`，但課次是閱讀
計畫按難度排序**算出來**的結果（見 silent-failures 第一節），重排一次就會整批
錯位而任何數字都不動。兩邊真正共有的是那一千詞：每題的 `targetWords` 記著
`ordinal` 與 `pointed`。用序號綁、順便比對附點詞形，對不上就**報錯不跳過**。
紙本在 `build_hebrew_full_reader.py` 的 `bind_exercises()`，線上在
`data/originalReaders/hebrew-full-reader.ts` 的 `bindExercises()`，兩支同一套判準。

**二、片語詞條沒有自己的 Strong 碼。** `עַל־דְּבַר`（序號 95）的 `strong` 是空字串、
`strongs` 有兩個碼。拿 `strongs.includes(entry.strong)` 去比會把正確的資料判成
同形異詞——第 5 課就中。空的 `strong` 要先讓過，同形異詞那一關是給單一詞位用的。

**三、綁定表要整份綁完才發布。** 綁到一半丟例外會留下半滿的快取，下一次呼叫
拿到它就當成完整的，沒綁到的課於是顯示成「這一課沒有練習題」——錯在第 5 課，
報出來的卻是第 5 課「沒有練習題」，真正的原因在上一段。先寫進區域變數，
全數綁完才寫進模組層的 map。

版面本身：標題「本課翻譯練習（10 題）」接在詞表之後、讀物之前；每題印題號、
出處或「自撰」、原文一行，底下一條橫線供作答。**中文一個字都不印**——連
`answerKeyRef` 都不送到頁面，免得哪天有人把它接成譯文。課次若定錨不足，
`note` 接在覆蓋率那一行後面照印。

紙本另有三處要跟著改，不改就是印著不存在的東西：封面副標（在
`build_hebrew_reader_data.py` 產生，改那裡也要改主檔 JSON）、〈這一本怎麼使用〉
第二張卡、書末〈來源與成品檢核〉那一條，還有「完成本課」清單第 2 項。

## 分冊：練習題會讓某些冊超過 500 頁

一本裝訂實體上限 500 頁（使用者 2026-09-08 定的），閘在
`render_and_check_reader_pdfs.py` 的 `MAX_READER_PAGES`。實測**練習題取代背誦之後
淨增約一頁／課**（希伯來 401 → 452 頁，50 課）。所以接版面之前先算：
`現有頁數 ＋ 該冊課數 ≈ 新頁數`，過 500 的那一冊要再切。

切的規矩（沿用既有的 `PARTS`，不是新發明）：

- 切點只落在**課與課之間**，課次編號一律不動——線上讀本、音檔與練習題都靠它對應。
- 同一種語言各冊厚薄要相近：與其 2＋3 切成 264／409，不如切成六冊各 300。
- 附錄只印在該半的**最後一分冊**。
- 改完 `PARTS` 要重跑 `render_and_check_reader_pdfs.py` 用實測值回填註解裡的頁數，
  不要留著舊數字——那個註解是下一個人判斷還有沒有空間的唯一依據。

2026-09-18 的實測基準（12pt、一課八頁、讀文按版面預算節錄之後）：
希伯來單冊 406、希臘四冊 183／189／241／236、拉丁三冊 349／159／165、
日文四冊 177／173／174／184。全部離 500 頁的上限還有很大空間——這一輪之後
**各語言其實都可以再收成更少、更厚的冊**（希臘上冊 372 頁可併成一冊、拉丁下冊
326 頁可併成一冊、日文兩半各約 360 頁可各併成一冊），但那是印幾本實體書的決定，
要問過擁有者，不要自己併。

🚨 切點要把**整冊的厚度**算平，不是把課文頁數算平：附錄只印在該半的最後一分冊
（希臘下冊那份就有 150 頁）。照課文頁數對半切，會切出 201／277 的一薄一厚。

## 「作者複核」這一欄到底是什麼意思

`reviewedBy: "author"` 不是蓋章，是一種寫法。希伯來那 369 句的草稿長這樣：


三件事構成「作者」：**一句一句寫**（不是丟給模型批量產生再整包收下）、**每句寫下
它的中文意思**（寫得出意思才表示真的知道自己寫了什麼；這份中文留在草稿裡，
將來編解答本直接取用，但**不進成品**）、**寫下這一句練的是哪幾個詞**。
草稿的 `note` 記下為什麼改寫——詞表重建、閘退回、句式踩到機械替換那個坑。

過閘不等於正確（規格上面那節已寫），所以順序是：寫 → 過閘 → 讀退回訊息改寫 →
再過閘。閘只能證明「這個詞形有人寫過」「這個詞教過」「二十詞都練到」，
句法與母音點得自己負責。

## 「這個詞根本練不到」——三本都會撞到，原因各不相同

閘一要求每個字形在語料出現過，閘二要求每個詞已教過，閘三要求本課二十詞全練到。
對某些詞，這三條**互相矛盾**，於是那一課不是難，是不可能。實測：

| 讀本 | 兩千詞裡卡住的 | 主因 |
| --- | --- | --- |
| 教會拉丁文 | 91 → 修完剩 30 | 詞彙出自 Collins、語料是武加大，**不是同一本書**；多數是「字形在、詞位欄是空的」 |
| 通用希臘文 | 16 → 修完剩 6 | 詞條本身就是變化形或變體（`εἶπεν`／`οὐ (οὐκ`），照詞位比對永遠對不上 |
| 聖經希伯來文 | 0 | 詞表就是從 WLC 抽出來的，語料與詞彙同源 |

修法分兩層，**先修可修的，剩下的才豁免**：

1. **credit 與「已教過」兩側都要有多條路線，由嚴到寬，第一條答得出來就不往下走。**
   詞位 → 詞條自己印出來的那個形 → 詞幹（六字母以上）。第二條是關鍵：
   `εἶπεν`、`ἦν`、`collaudate` 都靠它。它安全，因為要求寫出來的**就是**所教的
   那個形；當年 `missa` 出事是繞道 `mitto`，不是這一條。
2. **兩側的判準必須一致。** 拉丁踩過：credit 那側走了詞幹路線、「已教過」那側
   沒走，於是 `speciō` 被判「可以練」卻沒有任何一個形寫得出來——那一課拿到一個
   既練不到、又不能列入豁免的詞。判斷「一個詞可不可能練到」不要自己寫規則，
   **直接跑真正的閘**。
3. 剩下的（語料真的一個可用形都沒有）另立 `coverage.notAttested`，不混進
   `notPractised`，且該課 `note` 必須說明。與「定錨不足三題」同一個形狀：
   可以不足，不吭聲才算失敗。

**片語詞條要整組在同一句才算練到**（`εἰ μή`、`in saecula`、`male habeō`、
`aut . . aut`、`nōlī/nōlite`）。記給其中任何一半，這道閘對它就形同虛設。
🚨 片語比的是**字面形**不是詞位：`male habeō` 寫成 `male habet` 不算。

🚨 **定錨題的 targetWords 一律重算，不要沿用挖句時寫下的那一份。** 挖句器是用
當時的 credit 規則算的；規則改過之後，覆蓋率就與現在的閘對不上——拉丁下冊第 30
課因此出現一個「一邊說練到了、另一邊說沒有」的詞。

## 排完版一定要回頭讀 PDF——「排得出來」不等於「排對了」

`render_and_check_reader_pdfs.py` 檢查的是紙：頁面尺寸、字體有沒有內嵌、有沒有
空白頁、有沒有 U+FFFD、超不超過 500 頁。它對頁面上印的是什麼一無所知，所以
「四項全綠」與「第 30 課印的是第 30 課的題目」是兩回事——而這個系列最常見的
失敗正是後者。

`scripts/audit_printed_exercises.py {heb|lat|grc}` 補上後者：直接開 PDF 回頭比，

1. 每一課印滿十題；
2. 頁面上的十題，就是題庫裡「這一頁自己聲稱的那一課」的十題（課次取自頁眉，
   不是取自區塊出現的順序——順序對不上才是要抓的東西）；
3. 題目那一行零漢字；
4. 全書沒有任何一題印了兩次。

**右到左要換一種比法。** PyMuPDF 讀希伯來會把一行拆成視覺順序的片段、還會重覆
字母：`יוֹנֵק` 讀回來是 `ויֹוֹוֵנק`。照字串比會把五百題全判成配錯（實測 377 條
誤報、零條真的）。所以希伯來那一路改成「這一句最像題庫裡的哪一句」，比中的必須
是該頁應該印的那一句——足以抓到整頁配錯，抓不到同一句內部的字序顛倒，而字序
顛倒本來就不是 PDF 能證明的事。

實測：希伯來 500 題、拉丁 1,000 題、希臘 1,000 題全綠。

## 2026-09-16 擁有者裁定：「已教過」不再是退回的理由

原話：「按照程度來看，簡單的都可以先練習，沒有限制一定要本課教過的才行，
都去重新補滿。」

一個詞排在第幾課，是難度排序的結果，不是它本身難不難。把課次當成硬牆，代價是
一課的二十個詞裡有幾個**永遠**寫不進任何句子，而擋住它們的是排序不是語言。

改法：**第二道閘照記不照擋。** `verification.untaught` 仍照實記錄哪些詞超出本課
進度（日後要分級或標注時取得到），但 `passed` 不再看它，共用閘也不再因此退件。
第一道閘（語料有沒有這個形）原樣不動——捏一個沒人寫過的形仍然是錯的。

**連帶放寬語料範圍。** 拉丁上冊原本只驗武加大、希臘上冊只驗新約與七十士。那是
「本冊讀什麼」的範圍，不是「有沒有人這樣寫過」的範圍。拉丁上冊五十個練不到的
詞裡，四十九個在本讀本自己的下冊裡整篇印著（pāpa、liturgia、apostolicus、
catholicus、episcopālis、psalmista）。兩語都改成對整套讀本的語料驗。

補滿之後的殘值（四語兩千二百詞，notPractised 全部歸零）：

| 拉丁下冊 | 36 | 12 | December／Februarius／Aprilis、dioecesis、archidiaconus 等 |

### 🚨 同一輪抓到一個已經印進書裡的錯：序號當鍵，但序號每冊各自從 1 數起

拉丁的「練不到」是拿序號當鍵算的，而拉丁詞表的 `ordinal` 每冊各自從 1 數起。
`unreachable_words()` 收了兩冊的詞條，於是**上冊第 n 個詞的「練不到」整批蓋到
下冊第 n 個詞頭上**——下冊因此在紙本印過「本冊語料中無任何字形：medius」，
而 medius 在武加大裡到處都是。三十四個裡二十二個是假的，而每一頁看起來都正常。

改成只收本冊的詞條。**凡是拿序號跨檔綁定的地方，先問這個序號是全書唯一的
還是每冊重來的**：日文與希伯來是全書通編，拉丁與希臘是每冊重來。

## 日文特有的五種退回（2026-09-16，寫完一百課之後）

日文的閘與另外三語不同，退回的理由也不同。這五種各踩一次就夠：

1. **な形容詞詞條要寫成「な＋名詞」。** 詞條是「好きな」「静かな」「元気な」，
   寫成「好きです」斷出來的是光桿詞幹「好き」，那不在詞表裡，整句退回。
2. **否定用「〜ません」，不用「ない」。** 「ない」不在本讀本教的文法詞表裡。
3. **長度閘算的是實詞，不是 token。** 「もしもし。駄目ですか。」只有兩個實詞，
   會以「沒有通過語料驗證」退回而且不印理由——看到沒有理由的退回先數實詞。
4. **複合詞條會把組成部分吸進去。** 「サッカーを します」「おかねが あります」
   是整組的詞條，練到它不等於練到「サッカー」；反過來，複合名詞會吞掉接尾辭
   詞條（本屋 吃掉 屋、昼休み 吃掉 昼＋休みます、１番 吃掉 番）。接尾辭要放在
   の 後面才會被斷成獨立的名詞：「留学生の番です」。
5. **する 動詞詞條只有連 します 一起寫才記得到。** 詞條是「質問します」，
   「質問に答えます」裡的「質問」是另一個（沒教過的）詞。

另外，**助詞型詞條（から、まで、や、しか、か、が）只有被斷成名詞時才記得到**，
而那種位置學習者實際讀到的句子裡不會出現。可達性因此用兩個框架去問
（私の…です／私は…です），兩個都記到才算可達；只問一個，每個框架都會各自
誤放一個助詞過關，留下永遠補不起來的覆蓋缺口。真的過不了的就進
`coverage.notAttested` 並在 note 說明，與希臘的 `πτελέα` 同一處理。
