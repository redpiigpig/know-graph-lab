# 一課十題翻譯練習

2026-09-11 由擁有者定案，四本讀本共用。這一層取代原本每課兩節背誦經文的位置：
詞表 → 讀物 → **練習十題**。

## 定案的規格

| 項目 | 定案 |
| --- | --- |
| 方向 | **只做原文 → 繁體中文**。不做中文 → 原文（自學無人批改，回譯沒有唯一答案） |
| 題數 | 每課十題 |
| 組成 | **七題自撰 ＋ 三題經典原句**。原句是定錨：學習者永遠有正確樣本可對照 |
| 覆蓋 | 本課二十詞**全部**要出現，重複出現沒關係 |
| 生字 | **零**。題目中每個詞都必須是本課或先前課次教過的。不用腳註補生字 |
| 長度 | 三到八個詞，短句優先；課次越前面越短 |
| 語域 | 只能用經典本身的詞與世界觀，不得出現該經典世界以外的事物 |
| 中文 | 引用題取既有譯本；自撰題由作者自己寫 |

自撰為主是擁有者的決定，理由是純引用填不滿生字表：實測希伯來全五十課，
純原句只能覆蓋 71.6%，且第 1、2、3、4、7 課連十題都湊不滿。

## 三種出題法，只有兩種可用

**一、引用**（`kind: "quoted"`）。從語料挖出「全句每個詞都已教過」的整節或依原文
自己的停頓切出的子句。可靠度滿分：句子是經文，中文是既有譯本。
希伯來走 `scripts/build_hebrew_exercises.py`。

**二、自撰**（`kind: "composed"`）。作者寫句子，語料驗句。這是主力。

**三、機械替換——已驗證不可用，不要再試。** 拿原句當骨架、把某個詞換成形態標記
完全相同的另一個詞，產出的是詞沙拉：

> `וְחַי מֵאֶרֶץ שְׁכַב אָב יִפְקֹד שָׁנָה`

每個詞形都是真的、標記全對，句子不成話。句法不在形態標記裡。同類的失敗還有
同源賓語句式——`אַךְ נִגּוֹף נִגָּף הוּא` 的不定詞絕對式必須與主要動詞同字根，換成
`הִפָּקֵד נִכְבָּד` 標記依然全對而句式已壞。

## 機器閘擋得住什麼、擋不住什麼

`scripts/compose_hebrew_sentences.py --check` 是希伯來的閘，其餘語言照樣造。

**擋得住**（三條，全部是機械判定）：

1. 每個詞形必須在權威語料中實際出現過，同樣的子音與母音——捏造的變化形一律退回
2. 每個詞必須已教過——用未教的詞一律退回
3. 十題合起來必須涵蓋本課二十詞

**擋不住**：句法與母音點。實測 Haiku 寫的十句有八句過閘，其中三句仍有真錯
（`בַּיּוֹם הַשַּׁבָּת` 兩個冠詞疊、`וַחָזַק` 連接詞形錯、`שִׁמוֹ` 母音點錯）。
**過閘不等於正確**，自撰題一律要作者逐句複核。

「相鄰兩詞必須在語料中連用過」這道閘測過了，太稀疏不能用：`הכהן+מצא`
（祭司找到）這種完全正確的組合也會被判不合格。

## 產物 schema

```json
{
  "schemaVersion": "1.0.0",
  "languageCode": "hbo",
  "direction": "original-to-chinese",
  "itemsPerLesson": 10,
  "lessons": [{
    "lesson": 13,
    "items": [{
      "no": 1,
      "kind": "quoted",
      "ref": "Gen.18.21",
      "text": "…",
      "chinese": "…",
      "chineseSource": "和合本修訂版（2010）",
      "targetWords": [{"pointed": "…", "strongs": ["H…"]}],
      "verification": {"unattested": [], "untaught": [], "passed": true},
      "reviewedBy": "author"
    }],
    "coverage": {"lessonWords": 20, "practised": 20, "notPractised": []}
  }]
}
```

`kind: "quoted"` 必附 `ref` 與 `chineseSource`；`kind: "composed"` 的 `chinese`
由作者撰寫，`chineseSource` 留空，且 `reviewedBy` 必須是 `author`——
模型寫的草稿沒有作者逐句看過，不得標成已複核。

## 驗證閘

`scripts/validate_reader_exercises.py` 對每一本跑，全綠才可進版面：

- 每課恰十題
- 每課 `quoted` 至少三題，且每題有 `ref`
- 二十詞全覆蓋，`notPractised` 必須是空的
- 每題 `verification.passed` 為真
- 每題 `unattested` 與 `untaught` 都是空的
- `composed` 題的 `reviewedBy` 必須是 `author`
- 中文欄不得為空、不得含原文字符

## 已知的坑

- **maqqef 連寫**：`אֶת־הָאָדָם` 是兩個詞寫在一起。驗證前不先拆，整串查不到，
  會把正確的句子整批誤判。希臘的 crasis、拉丁的 -que 同理。
- **同形異詞**：撒上 4:18 的 `וְכָבֵד` 是形容詞 H3515，與第 13 課要練的動詞
  `כָּבֵד` H3513 不是同一個詞。用字形比對會放過，用 Strong 比對才擋得下。
- **引擎吐不出 JSON**：NVIDIA 那層對這類要結構化輸出的任務回的是推理散文，
  `--engine auto` 常拿到 0 句。要結構化輸出時明確指定引擎。
- **重音符號不可搬家**：馬所拉重音標的是該詞在**它自己那一節**裡的位置，
  搬到別句就是偽造。自撰題一律不標重音，只留母音點。
