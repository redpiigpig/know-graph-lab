# 銘文與紙草 Skill

希臘宗教沒有經書，但它有**石頭**。祭儀怎麼做、誰能進聖所、哪天獻什麼牲、死者在冥府該說什麼話——這些從來不寫成書，而是刻在神廟門柱、鉛板、金葉與墓碑上。

因此本藏經的 Κ 祭儀法、Λ 祕儀書、Ξ 聖所志、Χ 神蹟簿與整個羅馬卷 II／III，主體都是銘文。**這一批在中文世界近乎全空白**，是本藏經最有原創價值的部分，也是最花工的部分。

## 3. `status: 'inscription'` 的填寫規矩

```ts
{
  title_zh: '塞利農特淨罪法',
  title_orig: 'Lex sacra from Selinous',      // 學界通用題名，非直譯
  author: '塞利農特城邦',                       // 頒布者／刻立者，不是「佚名」
  era: '約前 460 年',                          // 刻立年代
  place: '西西里‧塞利農特',                     // 🚨 必填：出土地
  language: '古希臘文（多利安方言）',            // 方言要標，這是這批材料的價值之一
  extent: '鉛板兩面',                          // 載體與規模
  status: 'inscription',
}
```

**四條硬規矩**：

1. **`place` 必填。** 銘文的意義有一半在它立在哪裡——同一條祭儀法立在城門口與立在聖所內部，效力完全不同。
2. **`author` 寫頒布主體**（城邦／祭司團／聖所／信團／個人還願者），不寫「佚名」。銘文幾乎都知道是誰立的。
3. **方言要標。** 多利安、伊奧利亞、阿卡狄亞方言是這批材料的核心價值，尤其多多納鉛片（希臘方言學的一座礦）。
4. **`extent` 記載體。** 「鉛板兩面」「現存 4 石逾 70 則」「現存逾 4,000 片」——讀者要知道這是一塊石頭還是一整批。

## 4. 原文處理：斷句與補字符號

銘文原文帶一套 Leiden 體例符號，**進站上對照欄時不可擅自清掉**——清掉等於把推測當原文。

| 符號 | 意思 | 中譯欄怎麼辦 |
|---|---|---|
| `[αβγ]` | 石面已缺，編者補 | 中譯對應處加〔〕標示為補 |
| `(αβγ)` | 縮寫展開 | 中譯直接展開，不另標 |
| `⟨αβγ⟩` | 編者訂正刻工之誤 | 中譯照訂正本譯，`note` 記原刻 |
| `{αβγ}` | 刻工衍字，應刪 | 中譯不譯 |
| `⟦αβγ⟧` | 古代人為鏟除（damnatio） | **必譯並標明遭鏟除**——這往往是最有意思的一筆 |
| `[- - -]` | 缺漏長度不明 | 中譯作「……（缺）」 |
| `.α.` 或 `α̣` | 字母殘存不確定 | 中譯不特別標 |

> `⟦ ⟧` 特別重要：帝王崇拜銘文裡被鏟掉的皇帝名（如圖密善、蓋塔）是宗教與政治關係的直接證據，羅馬卷 V 遇到務必保留並在 `intro` 點出。

**斷行**：銘文以石面行為單位，行號是引用的基礎（`IG II² 1237, ll. 5–12`）。做逐段對照時**以石面行分段，不要按語意重排**，否則行號對不上就失去可引用性。

## 5. 翻譯規矩

1. **祭儀術語先過詞庫。** `/translation-glossary`（[[translation-glossary]]）。已定案：淨罪（καθαρμός）、贖罪牲（ἱερεῖον）、初穗（ἀπαρχή／ἀπάρχομαι，first-fruits 與 first-offerings 都譯初穗）、還願（ἀνάθημα）、入教（μύησις）、聖所（τέμενος）、聖林（ἄλσος）、聖休戰（ἐκεχειρία）。

2. **城邦官職依「春秋制」register 定名。** 走「官制與行政區‧朝代 register」那一頁（[[project_offices_register]]）。判定理由：希臘城邦是公民選任年度官、國老會、刻石成文法的政體，正對應 register 表上「春秋制」那一格（列國霸業、成文法、商業城邦，迦太基同列）；**不要套「戰國秦制」的郡／郡尉**——那一格配的是希臘化王國的 territorial 官制（Strategia→郡），不是城邦內部職官。

   已定名（安達尼亞祕儀規章，標【提】待校）：

   | 原文 | 中譯 | 依據 |
   |---|---|---|
   | ἄρχοντες | 執政 | 春秋列國之長；**「執政官」已配給羅馬 consul，不可共用** |
   | γερουσία／σύνεδροι | 國老會／國老 | 《左傳》「國老」；「長老會」「議事會」是現代譯法 |
   | ἐπιμελητής | 掌儀 | 周禮「掌X」體例（掌客、掌次） |
   | ἀγωνοθέτης | 司競 | 周禮「司X」體例 |
   | γυναικονόμος | 司婦 | 同上；「監察官」是明清／現代 register |
   | ἀργυροσκόπος | 校錢 | 驗銀錢真偽 |
   | ταμίας | 司庫 | 本即周制職名 |
   | ἱεροθύται | 祭祝 | 周禮祝官掌獻祭祝辭 |
   | ἱεροί／ἱεραί | 祠士／祠女 | **「聖職」是基督教詞不可用**；且非祭司，另有祭司 |
   | ῥαβδοφόροι | 執杖 | 職名不綴「者」（比執金吾、執戟） |
   | αὐληταί | 吹籥者 | 周禮「笙師」掌吹竽笙塤籥，籥近 aulos |
   | οἱ πέντε／οἱ δέκα | 五有司／十有司 | 周禮「三有司」體例；「五人團」是現代詞 |
   | ἱππόδρομος | 馬埒 | 漢語固有詞（《世說新語》王濟作馬埒）；「競馬場」是和製漢語 |

   **一律避開**：總督、行省、省長（明清 register），以及監察官、主持官、委員會、團、議事會（現代詞）。
3. **法條體例照原樣。** 祭儀法多為「若……則……」決疑體，中譯保留這個句式，不要改寫成流暢散文——那會抹掉它與利未記、與古代近東法典的可比性。
4. **金葉片的口令不要意譯。** 「我是大地與星天之子，但我的族類屬天」這種句子照字面譯，它是**口令**不是文學。
5. **數字與價錢照抄。** 埃爾希亞祭曆的牲品價錢是社會史材料，不要約略化。

## 6. 取源流程

1. 先在 **CGRN** 查（祭儀法類最快，直接給原文＋英譯＋註解＋書目）。
2. CGRN 沒有 → **PHI** 用編號或關鍵字查原文；**AIO** 查阿提卡的英譯。
3. 拉丁 → **EDCS**（涵蓋 CIL，可按編號直取）。
4. 都沒有（金葉片、多多納、德爾維尼）→ 記下標準校本書名於 `via`，標為**待補原文**，不要拿二手網頁充數。
5. 抓到原文 → 保留 Leiden 符號與行號 → 逐行翻 → 寫進站上對照。
6. 條目填 §3 四條硬規矩 → 驗（`vue-tsc` + `vitest`）→ commit。

## 7. 常見錯誤

1. **`place` 留空。** 銘文沒有出土地就等於沒有一半的意義。
2. **清掉 `[ ]` 讓原文「乾淨」。** 那是把編者推測當成石面實存。
3. **按語意重排分段，行號對不上。** 之後任何人都無法引用。
4. **把 `LSCG`／`LSAM`（Sokolowski 1955–69）當現行標準。** 它們仍通用但已被 CGRN 取代，**雙標**：`CGRN 52 = LSCG 18`。
5. **拿 Betz 的 PGM 英譯全文貼站上。** 有版權；原文編號可用，譯文自譯。
6. **連續高速爬 PHI／CGRN。** 見 §1 警告。

## 8. 工具

`scripts/hellenika_cgrn.py` —— CGRN 取源器。`--list` 看對照表與已抓狀態，`--fetch` 抓取。
每篇存成 `data/hellenika/sources/cgrn/cgrn-{n}.json`，含希臘原文（Leiden 符號已依 §4 自
`supplied`／`lost`／`line-number` 三個 CSS class 還原）、英譯、年代、出土地、載體、版面、
書目、註解與授權聲明。預設間隔 6 秒。

`scripts/hellenika_align.py` —— 入庫即翻譯。CGRN 的希臘原文與英譯都帶石面行號
（希臘 `{10}`、英譯 `(10)`），故對齊鍵直接用行號。產物 `cgrn-{n}.aligned.json`，
接上 `/hellenika/text/cgrn-{n}` 三欄閱讀頁。

**三道從實作中長出來的規矩**：

1. **逐篇先定專名表再逐批翻。** 每批獨立呼叫、彼此看不到對方，同一個專名會被譯成
   不同名字。首譯時 Zeus Meilichios 在第一段是「和善者宙斯」、第三段變「（宙斯）
   邁利希俄斯」，且與 Zeus Eumenes 撞成同一個中文名——同一塊石頭上兩個受祭對象被
   合併了，是實質錯誤。改為每篇先一次定名（含撞名檢查）再強制沿用。
2. **建不出專名表就不要翻。** 曾因額度用罄而降級用基礎詞庫翻完 34 段，那些譯文的
   專名必然前後不一致且不會有人發現。現在改為中止該篇、下一輪重試。
3. **依字數動態分批，不要固定段數。** 長段落會撐爆回傳長度，JSON 解析失敗整批報廢，
   而腳本只會安靜跳過、看起來像「沒東西可譯」。上限 2600 字或 6 段先到者為準。

### PHI 取源（CGRN 沒有的其餘各類銘文）

`scripts/hellenika_phi.py` —— `--fetch` 抓取，存成 `sources/phi/phi-{id}.json`。
正文結構：`<table class="grk">`，每個 `<tr>` 一個石面行，`<td class="id">` 放行號
（每五行才出現一次），`<span class="r">` 是補字（方括號已在內容裡），`<em>v</em>`
是 vacat。

🚨 **PHI 編號怎麼查**：站上 `/search?patt=<不帶重音的希臘詞>` 可查，結果頁含
`/text/{id}`；**瀏覽頁 `/book/{n}` 是 JS 驅動的，抓不到條目，別浪費時間**。
IG IV²,1 121 即由搜尋「ιαματα」查得 PHI 28551。搜尋不吃帶重音的字串與空格。

`scripts/hellenika_iamata.py` —— 治癒銘文切案並直譯。

🚨 **切案要切在行中，不能整行歸給新案。** 案號常刻在行的中間（石工不換行接著刻），
