# 博士論文計畫書

`/works/hcu-phd`（`writing_projects.kind='thesis'`）。正文 `public/content/works/hcu-phd-proposal.md`，送件檔由 `scripts/build_proposal_docx.py` 產生同名 .docx。

**題目**：《從彼岸向此岸的轉向：台灣佛教與基督教公共性之宗教史比較研究（1920年代–2020年代）》
**指導教授**：釋昭慧

## 三個定調的決策（改動前先讀）

**一、方法論是歷史學，不是宗教學。** 宗教學與比較神學的意義放到**第六章**才談，把歷史歸納命名為「人間宗教」。不要把希克／尼特／潘尼卡那套理論回顧提前到前幾章——先做歷史、後論理論，理論是研究的結果不是起點。這是整份計畫立論正當性的所在。

**二、題目只指認研究對象，不掛背景。** 東亞是第二章的前史（以既有研究綜合為主、不作獨立史料考證），所以**題目不列「東亞」**——掛進題目等於承諾一份不打算做的一手東亞研究，口委會照那個承諾要求。時間用「年代」而非精確年份：第二章實際起於 1919 三一運動、1921 文協，第六章寫到 2020 年以後，精確年份兩端都會差一點。

**三、兩條四人系譜是全書骨幹**：佛教＝太虛→印順→**傳道**→昭慧；基督教＝黃彰輝→宋泉盛→**王憲治**→黃伯和。四個位置對應「發動者—詮釋者—落地者—建制者」，這個同構是主要發現。傳道（妙心寺）與王憲治（台灣鄉土神學）研究最薄弱，也最有補白價值。

## 七章結構

一 研究方法與文獻回顧／二 東亞近代宗教變革（前史）／三 人間佛教在台灣的發展／四 台灣長老教會的公共神學發展／五 人間佛教與公共神學之比較／六 人間宗教的範式／七 結論。

**佛耶交會史與議題結盟放在第六章**，不另立專章——它在本研究中的作用是證明「人間性的共同」足以作為宗教對話與合作的基礎，屬範式的經驗檢證。第五章專責兩線比較，小結收在「人間性的交集」上以接第六章。

## 送件格式（比照原 Word 檔，不要自創）

段落順序：封面（校系中英名）→ 摘要 → 關鍵字 → **Abstract** → **Keywords** → 一 研究動機 → 二 文獻回顧與探討 → 三 研究方法與範圍 → 四 預期研究成果與貢獻 → 論文大綱草案 → 參考書目 → 附錄。

🚨 **中英文摘要都要有**（改版時漏過一次）。

`scripts/build_proposal_docx.py`：A4／頁邊 2.54cm／12pt 新細明體＋Times New Roman／行距 1.5／首行縮排兩字；`#` 主標 18pt 置中、`##` 14pt、`###` 13pt；參考書目自動改懸掛縮排；「摘要」之前一律置中視為封面。

**分頁**：Abstract／正文／論文大綱／參考書目／附錄各自另起一頁。分頁設在標題段的 `page_break_before`，**不要插只帶分頁符的空段**——後者會留下空行，標題剛好落在頁首時還會多出一整頁空白。

## 附錄：十個月工作計畫

助學金（研究助學金）用。辦法的硬規定：十個月為限、每月與指導教授討論二次以上、系所次月5日前送「研究生論文指導紀錄表」、學期補助結束繳「論文進度審查表」、**題目未經審查不得自行變更**。

附錄**只寫研究生要做的事**，逐月列工作與產出即可，不要寫指導教授的指導原則與紀錄方式（曾寫成五頁，已精簡）。排法是第一學期以讀為主（前兩月人間佛教、後兩月長老教會、第五月收束為第一章初稿）、第二學期以寫為主。
