# 自己的學術論文：改稿流程與體例

資料夾：`G:\我的雲端硬碟\玄奘\博一上\投稿\YYYY.MM.DD 名稱\`（日期＝截止日，例：`2026.09.25 印順文教基金會論文獎學金`）。

---

## §A 工作守則（違反過、使用者發過火的）

1. **docx 一交出去，正本就是使用者手上的 docx。** 之後改稿一律：先讀現檔 → 備份到 scratchpad → Word COM 就地改指定處 → 讀回驗證。**絕不從 md 用 `build_huiju_docx.mjs` 重建覆蓋**（2026-09-24 連五次蓋掉使用者改稿）。`build_huiju_docx.mjs` 只用在第一次產出。
2. **動手前檢查目標檔的 `~$` 鎖檔**（只查目標檔本身；資料夾裡常有別檔的陳舊鎖檔）。使用者開著就不碰，改成「給文字讓他貼」。
3. **只改使用者指定的範圍。** 使用者說「第三節以前都改好了」，全域規則（例如短詞改字型）就不能套到前面；要套全域先列出影響範圍。
4. **使用者刪掉的東西不要「修回來」。** 比對備份發現內容不見，先問，不要自己補（曾把使用者刪的「轉引自 Bingenheimer」補回去）。
5. 改完一定讀回，回報「改了哪幾處、哪幾處沒找到」。每次動手前的備份檔名寫清楚時間點。
6. 查驗先查自己手上的：站上印順全集 JSONL、CBETA XML、研究資料夾、使用者舊論文（`public/content/works/*.md`、`thesis/*.txt`、`papers/*.txt`）——藍吉富出處就是在使用者自己另一篇論文的註裡找到的。

## §B 註腳體例（使用者定案）

| 項目 | 規則 | 例 |
|---|---|---|
| 出家人作者 | 註與書目一律「釋某某」；正文稱「導師」；書名號／篇名號內不改 | 釋印順，《永光集》；〈新刊紹介：印順著『…』〉不改 |
| CBETA | p. 單頁、pp. 跨頁（CBETA 官方格式，曾改成「頁」又改回）；**只到頁，不到欄**（不要 5a） | CBETA, Y29, no. 29, pp. 14-15 |
| 序文頁碼 | CBETA 的 a 前綴保留，前面標〈自序〉 | 《印度之佛教》〈自序〉，CBETA, Y33, no. 31, p. a7 |
| 單篇文章 | 一定帶收錄書名 | 〈遊心法海六十年〉，《華雨集》第五冊，CBETA… |
| 每條註獨立 | 不用「同上註」「同註 N」「同文」「前揭」，一律寫全 | — |
| 收入論文集 | 「收入某某主編，《書》」；作者自己的論文集重複名字，不寫「氏著」 | 收入江燦騰，《當代台灣人間佛教思想家》 |
| 轉引 | 找得到原始出處就直接引原始，不寫轉引；找不到才「轉引自」 | 江燦騰〈台灣當代最偉大的佛教思想家印順盛正〉，《福報》第 62 期（1989 年 4 月 17 日） |
| 出版資訊 | 正文提到的書名，除轉引外都要有出版資訊的註，並列入參考文獻 | 高崎直道，《如来蔵思想の形成》（東京：春秋社，1974） |
| 頁碼格式 | 「頁」與數字間空一格 | 頁 13-72 |
| 註號位置 | 放在標點後；「」或（）後也可；「」後緊接，或。時註號放標點後；專指某詞／某人時可緊跟該詞 | …研究成果」。¹⁹ |
| 註腳字 | 新細明體 10pt | — |

**日文引文**：正文只放中譯（標楷體），日文原文整段放該註最後「原文：「……」」，中間省略用「……」。中譯要逐字對原文，**不可把別頁內容併進這句的中譯**；選放進註的原文段落，要能支撐正文每個要素（伊吹 2018：正文寫「初期佛教、初期大乘與中觀」，頁 32 那句沒有中觀，要換頁 59）。

**人物生卒年**：正文第一次出現給生卒年；日本人不附羅馬拼音（漢字即原文）；古人有固定漢譯不附原文（多羅那他、宗喀巴、達摩）；西方人名本來就寫原文；**查不到就不標**（不要寫「生卒年不詳」）；第一次出現在引文裡就標在下一次正文出現處。生卒年派 agent 查維基／NDL 典據／DILA 並標可信度。

**用字**：通用「台」不用「臺」（書名原字除外）；全文繁體。

## §C 引文規範

- **整句引用用標楷體**；三、四字的詞語（無標點且 ≤7 字）不算引用，用新細明體。「玄奘以來第一人」只有第一次引用那處標楷。
- **能完整引一句就不要切成兩三段**，省略用「……」。對方的說法也要引完整。
- **引號內必須逐字是原文**。縮寫、改寫不可加引號（「高楠順次郎已使用過」「引用日人研究成果」都曾被抓）。
- 所有引文要跑一次**全集逐字比對**（去標點後子字串比對）；比對不到的多半是漏了夾註（「宏闡中期佛教之行解（梵化之機應慎）」）。
- 題目中關鍵稱譽第一次出現就要給出處；沒頁碼的書不用，換有頁碼的出處。

## §D 參考文獻

- 分類：一、原典文獻／二、中文專書、論文／三、日文專書、論文／四、西文專書、論文。
- 排序：原典依作者筆畫（釋太虛 4 畫在釋印順 6 畫前），同作者依 CBETA 冊號；中文依姓氏筆畫；日文依姓氏讀音五十音；西文依姓氏字母；同作者依年。
- 日文判定不能只看有沒有假名（水野〈新刊紹介：印順著『原始仏教…』〉全漢字）；日文書的中譯本放中文類；華人用日文寫在日本刊物的放日文類。
- **註與書目要上下對齊**：跑腳本抽出註腳所有《》〈〉，對參考文獻找漏列；也反查書目裡沒被任何註引用的（《教制教典與教學》曾是孤兒）。
- 小節標題不要留 markdown 的 `### `（轉檔殘留）。

## §E 結構與論證（使用者偏好）

- 以中文材料與傳主自述為主，外文材料為輔（獨立一章），並在方法說明聲明外文以 AI 翻譯輔助、原文附註腳。
- 年代要順；刻意倒敘時用一句話點明（「這份不盲從，有其更早的根柢」），倒敘段內部照年代走。
- 結論：分點歸納後，限制一段接「儘管如此，本文所設定的問題已可得到回答」，**不要再重述各點**；最後可引傳主原話收尾，但同一引句全文只出現一次。
- 摘要壓在一頁內（約 450–550 字）：問題 → 三層次 → 結論。
- 避免 AI 味：不堆社會學理論名詞，以史料考證為主，使用者能親自複核每一條。
- 敏感團體：傳主相關道場之間有張力（福嚴／弘誓），申請文件與自傳中只在必要處（論文題目）提一次。

## §G 申請文件

- **申請表**（.doc）：Word COM 填（LibreOffice 會把浮動框跑版）；照片從 `資料\身分資料\06 證件照\`；題目等欄位字級依使用者（印順基金會那份改 14 號）。
- **自傳**：A4 電腦打字、≥800 字、須含學佛經歷。參考 `玄奘\博班申請\個人自傳.pdf`，但事實以使用者最新確認為準（皈依是 2022，舊自傳誤作 2023）。不寫「座右銘」這類誇飾；「回饋教界與社會」。
- **在學證明**：學生證正反面影本（背面要有當學期註冊章），實際尺寸 85.6×54 mm 排一頁 A4。
- **列印合併檔**：依申請辦法條列順序（資料表→曾發表論文→自傳→在學證明）；目標 PDF 常被使用者開著 → 先存 scratchpad，說一聲再覆蓋。
- **論文匿名**：PDF 內文與 metadata（author）都不能有姓名，交件前用 PyMuPDF 檢查。
- **投稿信**：Gmail `create_draft`（不附件，使用者自己上傳），寫清寄出日期、附件清單、在學證明與免附成績單理由。

## §H Word COM 片段與坑

```python
import win32com.client as w
app=w.DispatchEx('Word.Application'); app.Visible=False; app.DisplayAlerts=0
doc=app.Documents.Open(path)
r=doc.Content; r.Find.Execute('錨點文字'); r.Collapse(0)
fn=doc.Footnotes.Add(Range=r)          # Text 參數無效，要另外設
doc.Footnotes(fn.Index).Range.Text='註文'  # 字型取 Footnotes(n).Range.Characters(2)（第 1 字元常是空白）
```
- 加註後編號自動後移；若有「同註 N」要同步 +1（現行體例已禁用同註）。
- Find 超過 255 字會失敗；長段落用 `Range.SetRange(start,end)` 依位置改，改前 assert `r.Text` 等於預期。
- 移動段落用 `dest.FormattedText = src.FormattedText` 再刪原處，註腳會跟著走；複製標題段時小心留下重複段。
- 註號後殘留半形空格（轉檔產物）要清。
- `ExportAsFixedFormat` 目標檔被開著會報「唯讀」；ReadOnly 開啟後異常中斷會留隱形 Word。
- 全文逐字稽核：從 `word/document.xml`、`word/footnotes.xml` 解壓讀（不必開 Word，也不怕鎖檔）。
- CBETA 頁碼：`raw.githubusercontent.com/cbeta-org/xml-p5/master/Y/Y29/Y29n0029.xml` 找 `<lb n="0008a01" ed="Y"/>`；太虛全書用 `cbdata.dila.edu.tw/stable/toc?q=…&canon=TX` 找篇目，再抓 TX XML 算頁碼範圍。
