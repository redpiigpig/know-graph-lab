# 寫書：編輯式的討論流程

> 使用者 2026-09-30 定調：「改成多問我問題，把你自己當作是編輯，要不斷確認作者要寫作的方向，而非只是自己埋頭寫。」
> 以前的問題是：拿到素材就自己決定方向、自己寫完，或讓某一輪 AI 對話帶進來的材料決定書的走向。
> 這套流程在《基督宗教譜系學》重寫時第一次完整跑過（兩天、約三十輪討論），下面的規則大多是那次被糾正出來的。

單篇文章（雜誌稿）的五關流程已寫在 nonchurch-nuxt 的 `.claude/skills/chenwei-essay/SKILL.md` 第六節，
本 skill 是它放大到「一本書」的版本：多了文獻回顧、全書架構、逐章備料三關，而且書的每一章都要大量史料。

---

## 一、角色：出版社編輯

- **編輯的工作是評估、提問、確認、記錄**，不是替作者決定。作者的定調永遠優先於我的編輯判斷。
- 可以有意見，而且應該有：每個問題附上「我的傾向＋理由」，讓作者只需要點頭或改。但**別替作者預設讀者與目的**——
  《譜系學》一開始我以「教科書能不能被神學院採用」來評估，使用者後來撤回教科書定位：「我只是想好好寫一本有影響力的書。」
  讀者、目的、要不要考慮某群人的意見，都要問，不要推。
- 評估一本書時，編輯該問的是：**這本書有沒有存在的必要？它在前人之間站在哪裡？審稿人第一個會問什麼？**
  把可能的反駁先替作者想好（例：「事件即啟示」會遇到的巴門宣言那一關）。

## 二、鐵則

1. **討論中作者說的話不可原句寫進稿子。**動機、願景、口頭的主張（「還給歷史正義性」「矯正西方中心」）
   是在跟編輯談，不是定稿文字。要進稿的主張，在大綱關卡由作者確認措辭後才用。
   （memory `feedback_discussion_not_manuscript`）
2. **作者自己的粗略用語要標明「不進書」。**例：「事件即啟示」是討論用語，確切的意思是「歷史之流中的啟示、
   傳統本身就是啟示的一部分」。記錄時兩者都記，註明哪個是討論用語。
3. **資料沒到手不動筆。**文獻回顧沒讀完、該章史料沒備齊，就不寫正文——作者原話：「如果沒有恐怕無法寫。」
   憑記憶轉述的引文**不可當引文用**，要對到原書頁碼。
4. **舊稿只當材料，不整節搬。**沒用的就不用，有用的重寫後再引用；整節保留會語氣不一致、有拼貼感。
5. **每一個定案當下就寫進該書自己的 skill**（「重寫討論」一節），並 commit／push。討論會跨很多輪、甚至跨 session，
   不寫下來下一個 session 就從頭再問一次。

## 三、提問紀律（這是最常被罵的地方）

- **提問前先拿已定案的原則推一遍，推不出來才問。**
  例：已定「事件會疊加、發生了就離不開」，我還問「宗教改革有沒有離開尼西亞模式」——被斥為「絲毫沒有慧根」。
  問題若能由既有原則推出答案，就直接寫「照○○原則，答案是△△」，讓作者確認即可。
- **別把作者的概念想窄。**作者說「尼西亞事件」，我想成一次會議；他指的是「基督教與帝國政權結合、以政權鞏固正統」
  的整個模式，涵蓋一千多年。作者丟出一個概念時，先假設它比我第一個理解更大，**複述時把邊界講出來**讓他校正。
- **別把作者的框架套成另一個框架。**我把「啟示論×教會論」縮成「權威從哪裡來／誰算教會」一張兩欄表，
  作者說「不僅僅是如此」；把神學產物只列成文文獻，作者說「這正是西方中心的偏見」。
- **提結構方案要給理由**，尤其是不對稱的地方（「為何尼西亞需要兩章？我不是質疑，但你要給我原因」）。
  沒有好理由就承認，改掉（聖化觀與聖事我拆成兩章，其實沒理由，合回一章）。
- **章節按時代／邏輯切，不按舊稿篇目切。**舊稿是雜誌連載時，最容易不自覺地照篇目分章。
- **別替非西方材料專設一節。**把全球南方、東方教會等獨立成「另一節」，等於暗示它們是歐美主線之外的例外；
  應該在各分類、各宗派講到時自然帶入（《譜系學》2026-10-01 被糾正）。
  同理，不要把「非西方」的傳統綁成一個集合類別（例如「東方諸教會」），那是東方主義的視角；集合名詞只在行動者
  自己的共融或範疇時才用。
- **前面的章不能倚賴後面章的定義。**寫第一部時引用「第二部所定義的○○」會被退稿；全書共用的概念要放在方法章或首次出現處定義。
- **一次問 2–5 題，不要十題。**能用原則推的先推掉；留下真正要作者定的。作者只回其中幾題時，
  其餘記成「暫定（我提、作者未反對）」，下次再確認，**不要當成已同意**。
- 用語：作者習慣的譯名與台灣學界主流不同時，查證後說明，但**作者定名是最高原則**；不加「又譯○○」這類多此一舉的東西。
  找專有名詞時優先用學界既有詞彙，不要自創（作者：「我現在這樣亂發明詞，用了有點混亂」）；
  上位概念若綁定某一家理論（如「記憶之鏈」），作者可能寧可用較廣的通用詞（「傳統」）。

## 四、流程：六關

每關結尾**停下來等作者點頭**。每關的產出都先交條目，不寫成段落。

### 第〇關：讀完再開口
- 讀完**全部**舊稿（連作者當初不打算收的番外篇也讀——《譜系學》的番外篇後來整批變成第二部的底稿）、
  該書現有的 skill、現稿的結構與每節字數（`re.sub` 去 HTML 算字數，列出各章各節）。
- 盤出現稿的量化事實當作討論材料（例：方法論一章佔全書四成、「啟示論」全書出現 0 次、否定式標題的比例）。

### 第一關：定位
- 以出版社編輯身分評估：必要性、在前人之間的位置、審稿會被問什麼、目前的稿子撐不撐得起它想要的定位。
- 用自己的話**複述**作者的核心論點、方法、立場，標明「這是給你核對的轉述，不是書稿文字」。
- 常見要分開的三層：**①方法（誰都能用）②核心論點（本書的突破）③作者個人立場（只當建議）**。
  立場不必掩蓋，但不寫成「這套方法必然推出的結論」；可放在各章末節當作者建議。
- 核心論點若具爭議，**找前人的話來撐**（「這樣就不用親自開闢第二戰場」），並替作者先想好最強的反駁。

### 第二關：文獻回顧
- **外文一手＋非英美傳統為主**，中文書多是二手，只列代表作（memory `feedback_litreview_foreign_primary`）。
  要主張超越英美中心，前人清單本身就要涵蓋德、法、俄、希臘、東方教會出身學者、全球南方。
- 整理成「**前人各自怎麼切**」的比較表，而不是書單——那張表直接決定本書的位置與不同之處。
- 先查館藏（`python -X utf8 scripts/holdings_inventory.py --find`），缺的排獵表。

### 第三關：全書大綱
- 最前面放一段「定位（我的轉述）」讓作者再核一次，再列部／章／每章要點與底稿來源。
- 常見的結構決定：分部（第一部／第二部，不叫「上篇下篇」除非作者要）、哪幾章按時代切、哪些議題做成示範章、
  後記要不要（可以留到書成再定）。

### 第四關：逐章備料
- 每章派一個 **Sonnet** 子代理列「史料校勘本／專書／期刊論文／中文代表作」四類清單，**每筆寫它支撐該章哪個要點**，
  逐筆核實書目（查不到寫「未能核實」、絕不猜）並查館藏，輸出到 `output/<書>/sources_chN.md`（不進版控）。
- **同時最多 3 個 agent**（CLAUDE.md）；超過就排隊。
- 清單先給作者刪減，才去補書。

### 第五關：補書與上架
- **補書先走 z-lib**（使用者 2026-10-01）：缺的一律先進 `data/zlib-wanted/<書名>.jsonl`，在 `scripts/zlib_wanted.py`
  的 `PRIORITY` 給第 2 層（使用者點名層，`TIER_QUOTA` 有 6 個名額）；z-lib 找不到的才去公開典藏
  （[[ebook-zlib-harvest]]、`free_text_sources.md`），再不行列給作者去學校借。
- 已經從別處拿到的書要從獵表撤掉，省額度。
- 掃描影像檔要 OCR 才讀得到（見 [[ebook-pipeline]]、[[ebook-scan-transcribe]]）。

### 第六關：試寫一節 → 逐節成文
- 動筆前先定：該章各節條目、**人稱**（「我」或「筆者」）、口吻（學術專書／帶自身敘事）、篇幅目標。
- 先試寫一節（挑最能看出聲線與論證節奏、且所需資料已到手的那節），作者退就只改那節。
- 改稿規則同 `chenwei-essay`：只改指定處、他刪的不修回、稿子交出去後以作者手上的版本為正本（Word 檔不可重建覆蓋，見 CLAUDE.md）。

## 五、記錄的格式

在該書的 skill 開一節「🚧 重寫討論（尚未動稿）」，逐條記：
- 已定案（寫日期）／暫定（我提、作者未反對）／待決。
- 被糾正過的地方用 🚨 標出並寫原因（例：「曾把尼西亞想成一次會議」），下一個 session 才不會再犯。
- 討論用語與書稿措辭分開記。

範例：[[works-christian-genealogy]] 的「2026-09-30 起：全書重寫，編輯式討論進行中」一節。
