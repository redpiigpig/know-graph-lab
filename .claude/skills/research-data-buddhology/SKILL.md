# 當代佛學研究（/research-data/buddhist-studies）

收二十世紀以來的佛學研究書目。2026-09-11 開卡，是
[[research-data-theology]]「當代神學研究」的佛學版——架構、欄位、腳本命名、頁面結構
一律比照，只換配色（神學 indigo，佛學 amber）。

## 🚨 與別張卡片的邊界

| 材料 | 歸哪裡 |
|---|---|
| 大正藏／卍續藏／漢譯南傳的**經律論原文** | [[scripture-tripitaka]]（/tripitaka，3,784 部全文） |
| 二十世紀以來學者寫的**研究專著** | **本卡片** |
| 弘誓雙月刊、學團日誌、玄奘佛學研究學報等**刊物典藏** | [[research-data-hongshi]] |
| 中華佛學學報、法鼓、臺大佛學研究等**期刊篇目與卷期頁碼** | [[research-data-airiti]]（卷期頁碼只有華藝有） |
| 印順、太虛、聖嚴的**全集** | `/collected-works`（見 [[ebook-collected-works]]），不算圖書館館藏 |

判準跟神學那條線一樣：**原典 → 經典對照工具；研究 → 研究資料卡片。**

## 🚨 語言比重是硬要求，不是「有就好」

使用者明確交代過（並見 `feedback_dazangjing_diversity`「越近代越不可西方中心」）：

```
日 + 德 + 法 合計 ≥ 全部書目的 1/3，且每一種單獨 ≥ 10 筆
英文不得佔到八成
```

第一輪達成：**英 113（46%）／日 55（22%）／中 32（13%）／法 24（10%）／德 23（9%）／韓 1**，
日德法合計 102 筆＝41%。補書目時要維持這個比例，不能一路補英文把它稀釋掉。

三條學術傳統各自不可缺席的名字：

* **日文**——中村元、宇井伯壽、平川彰、高崎直道、藤田宏達、下田正弘、柳田聖山、
  望月信亨、牧田諦亮、赤沼智善、水野弘元、辛嶋靜志、船山徹、佐佐木閑；
  批判佛教那條線**三人都要**（松本史朗、袴谷憲昭、伊藤隆壽）。
* **德文**——Oldenberg、Lüders、Waldschmidt、Frauwallner、Schmithausen、Schlingloff、
  von Hinüber、Bechert、Geiger、Steinkellner。哥廷根的兩套研討會論文集
  （最古聖典的語言、佛陀年代判定）是這一系的代表。
* **法文**——Burnouf、Lévi、La Vallée Poussin、Przyluski、Lamotte、Demiéville、
  Bareau、Mus、Filliozat、Gernet、Strickmann、Faure。法國在中觀、律藏、
  敦煌與禪宗史上份量極重，缺了這一塊書目會歪。

⚠️ **日文書名有漢字就照原漢字寫在 `title`，不要另譯**（`title_zh` 放繁體化的同一書名，
の→之／的）。只有純假名書名才另譯，例如「出家とはなにか」→《何謂出家》。
見 `feedback_translation_register_and_titles`。

⚠️ **寧可不收也不要編造。** 日文與法文著作的年份與書名特別容易記錯，拿不準就換一本
確定的。`zh`（中譯本）欄尤其——只在確知有中譯本時才填，第一輪只填了七筆
（韋伯、沃德爾、許理和、末木文美士、舒馬赫、德容、謝和耐）。

## 書目的欄位

`data/research-data/buddhist-studies/bibliography.jsonl`，一行一筆：

```json
{"area":"gender","author":"Shi Chaohwei 釋昭慧","author_zh":"釋昭慧","year":2002,
 "title":"千載沉吟——新世紀的佛教女性思維","title_zh":"千載沉吟——新世紀的佛教女性思維",
 "lang":"zh","note":"二〇〇一年廢除八敬法運動的理論文本","zh":"（有中譯本時才填）"}
```

* `area` ∈ method / textual / history / gender / social / institution / doctrine
* `region` 只有 history 用
* `lang` ∈ en / ja / zh / fr / de / ko
* `author` 寫原文姓名，中日韓學者用「羅馬字 漢字」並列（比對只取最後一段，所以漢字要在後面）
* `author_zh` 是比對的關鍵欄，**寫最短的通行形**：印順而不是釋印順／印順法師，
  否則對不上館內的兩種寫法
* `in_library` 是跑腳本時算出來的，**不要寫進 jsonl**
* 不可有重複的 (`author_zh`, `title_zh`)

## 🚨 「已入館／缺」比對有兩個相反的壞法

`scripts/buddhist_studies_index.py` 的 `in_library()`。兩種錯都不會報錯：

1. **只拿原文題名比** → 得出「248 本幾乎全缺」。因為館內題名九成是中文，
   `Histoire du bouddhisme indien` 當然對不上《印度佛教史》。後果是把已經有的書
   全倒進獵表重抓。
2. **只拿題名比** → 拉莫特、平川彰、沃德爾、聖嚴四本《印度佛教史》被判成同一本；
   館裡光《中國佛教史》就有蔣維喬與鎌田茂雄兩種。後果是以為有而其實沒有。

現行作法：題名（原文與中譯都比）命中之後，**還要作者對得上**才算；作者欄空白的
只有在題名夠獨特（八字以上）時才採信。取寧可漏報的一側。

### 比神學那支多做的一件事：切破折號

`key_words()` 的分隔字元多了 `—` 與 `–`。日文書名慣用
「日本仏教史——思想史としてのアプローチ」這種長副標，館內中譯本卻只叫《日本佛教史》，
不切破折號整批對不上（實測：切了之後末木文美士那本才命中）。

### 🚨 命中率 5.2% 是實情，不是故障

第一輪 248 筆只有 13 筆在館。動手「修」之前先看這三件事：

* 館內 `category='世界宗教' AND subcategory='佛教'` 共 **313 筆，其中 282 筆是
  `collection='collected-works'`**——印順、太虛、聖嚴三套全集的個別卷。那是**原著不是研究**，
  且依 `feedback_collected_works_not_in_library` 本來就不算圖書館館藏。
  真正的二手研究**只有 31 本**（加上觀音信仰史那一本共 32）。
* 那 31 本逐本核過了，命中的 13 筆全是真的（印順六筆、湯用彤、蔣維喬、沃德爾、
  末木文美士、卜正民、Madsen 各一）。沒有漏抓。
* 所以低命中率反映的是**館藏真的很薄**，這正是本卡片以策展書目為主的原因。

判斷比對是否壞掉的實際方法：拿「館內確定有的那 31 本」裡與書目重疊的幾筆去驗，
不要看整體百分比。

## 館藏區用了哪些桶

```python
LIBRARY_BUCKETS = [("世界宗教", "佛教"), ("世界宗教", "佛教/觀音信仰史"), ("佛學", None)]
```

這是 2026-09-11 實際查 `ebooks` 表得出的，**不是猜的**。查證時發現的事：

* 世界宗教底下與佛教相關的 subcategory 只有這兩個。
* 另有一本被歸在 category `佛學`（subcategory `佛教倫理學`）——昭慧法師《心靈的交會》，
  是全集那一套，孤例。
* **「東亞宗教」那 42 本不收**：逐本看過，幾乎全是儒教與道教（道教簡史、朱熹的歷史世界、
  製造儒家…），只有《佛教與儒教》一本沾邊。用 subcategory 名字猜會收進一堆不相干的。

`library_stats()` 會把全集與一般館藏**分開報**，頁面上全集那幾格用紫色標示。
混在一起講「館藏三百本佛學研究」是灌水。

## 館藏資料本身的兩個坑

* `ebooks.author` 有 13% 放的是書名、11% 空白（見 [[research-data-theology]]），
  任何靠作者佐證的比對都會低估。
* **館內有錯字**：《如來藏思想》的作者被打成「高崎宣道」，正確是**高崎直道**。
  書目寫正確名字，於是這本對不上（判成「缺」）。這是正確的取捨——不要為了讓數字好看
  去把書目改成錯的。要治本得清 `ebooks.author`。

## 建置

```bash
python scripts/buddhist_studies_index.py            # 建索引
python scripts/buddhist_studies_index.py --wanted   # 另外吐出缺書獵表
```

輸出 `public/content/research-data/buddhist-studies/index.json`（進版控），
缺書獵表寫到 `data/zlib-wanted/buddhist-studies.jsonl`，交
[[ebook-zlib-harvest]] 的每日排程去找。

### 🚨 獵表這個檔名早就有人在用

`data/zlib-wanted/buddhist-studies.jsonl` **在本卡片開卡前就存在**——
[[ebook-zlib-harvest]] 手工策展過 22 筆 `bs-*`（威廉斯、格辛、卡魯帕哈那、
戈麥斯《極樂國土》等）。第一次跑 `--wanted` 直接覆寫，把那 22 筆默默刪掉且毫無錯誤訊息，
是靠 `git status` 顯示 `M` 而非 `A` 才發現的。現在 `--wanted` 改成**合併**：
本輪產生的照新的寫，本輪沒產生到的舊 key 原樣保留。日後在別的卡片複製這支腳本時
要記得檢查獵表檔名有沒有撞到。

### 🚨 獵表的 key 對中日文書名會整批互撞

`key` 的 slug 只留 `a-z0-9`，日文與中文書名 slug 完之後**一律是空字串**，
於是全退到「區-年份」這個鍵上互相覆蓋——實測撞掉 11 筆，而且不會報錯，
只是獵表默默少了幾本。現在的退路是接作者漢字（`bs-method-1989-袴谷憲昭`），
再撞才補流水號。神學那支腳本有同樣的結構，但因為書目幾乎全是西文所以沒發作。

頁面：`pages/research-data/buddhist-studies/index.vue`（七區＋館藏），
卡片掛在 `pages/research-data/index.vue`。

⚠️ PostgREST 沒帶 limit 會**靜默截在 1000 筆**（見 `feedback_postgrest_silent_1000_cap`），
`_paged()` 一定要用，別改成單次查詢。
