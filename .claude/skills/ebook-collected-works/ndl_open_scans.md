### 本輪加的兩道保險

### ⛔⛔ Haiku Vision 在這批材料上會**編造內容**（2026-09-07 實測，勿再試）

使用者明確授權用 Haiku 之後跑了，結果比「跑不動」更糟：**它會吐出通順但整段虛構的日文。**

拿影像 3 左半頁（標題頁＋第一章開頭，我自己看原圖讀得清清楚楚）當對照：

| | 內容 |
|---|---|
| **原圖真值** | 近頃「無教會主義」といふことが、日本の基督教界の一つの大きな問題となつてきた… |
| Haiku 輸出 | 宗教と「無教會主義」と称することは、日本の基督教發展の二つの大きな問題であつた… |

作者名還從「畔上賢造」變成「昭上賢造」「卍上賢造」「唵上賢造」（每次不同），
目次整頁消失，第一次跑時甚至憑空生出一份**完全不存在的目次**
（第一 無教會主義の本質／第二 信仰的基礎…頁碼到 175，而全書只有 18 張影像）。

**排除過的變因**（不是這些的問題）：

| 變因 | 處置 | 結果 |
|---|---|---|
| 解析度太低 | 1800px → 全解析度 3575px | 字數 9,588→16,072，仍在編 |
| 跨頁沒切開 | 加 `split_spread_boxes()` 切左右頁（各 1787×2787） | 切圖經目視確認正確，仍在編 |
| prompt 太鬆 | 改成嚴格逐字 prompt（禁止推測／讀不出寫 □） | **更差**（359 字，連「教派ではない」都不見了） |

失敗模式是**部分錨定的編造**：它讀到零星字詞（「教派ではない」「一つの大きな問題となつてきた」），
再用通順日文把中間補起來。這比完全讀不出來危險得多 —— 每一頁單獨看都毫無異狀。

**結論：這批直排舊字舊假名不要用 Haiku Vision。** 不是 prompt 問題，也不是解析度問題。

### ⛔ OCR 卡在哪

`gemini-2.5-flash` 免費層是 **20 requests／day／key** 的**日額度**（當天不恢復，
見 [[reference_gemini_free_tier_quotas]]）。本輪開跑時當日額度已被其他工作用完，
兩把 key 連續 429 → 依 [[feedback_ocr_two_strike_quota]] 自動退出，**0 頁完成**。

### ✅ 後來怎麼解的：**根本不是沒額度**

真正的原因是 `ocr_page()` 把「兩次連續 429 就退」實作成「試兩把 key 就放棄」，
而本機有 **7 把 key**，另外 5 把從沒被試過。我因此誤判成「今天沒額度」，
才繞去試 Haiku Vision（結果它會編造）。

**日額度在台灣時間 15:00（太平洋 00:00）重置**。修好 key 迴圈之後一次跑完 18 頁。

🚨 **教訓**：two-strike 那條規矩的本意是「池子乾了就別再捶」，不是「試兩把就放棄」。
判斷「沒額度」之前先確認**所有** key 都試過了。

### 這一輪踩到並修掉的四個坑

1. **目次被吞進第一章**：NDL 是跨頁掃描，一節的第一張影像常常還印著別的東西
   （目次、書名頁、前一章結尾）。整張當內文的話，整份目次會跑進第一章。
   → `strip_before_heading()`：正文從該節自己的章名之後開始，**取最後一次出現**
   （章名在目次裡也會出現一次，取第一次等於沒切）。
2. **canary 低估好的 OCR**：Gemini 把 9 個章名全讀對了，canary 卻只給 56%——
   因為書上印「敎」「現狀」而 NDL 索引寫「教」「現状」。比對前先正規化異體字後
   是 89%，只剩「起源→源」一個真的漏字。**異體字表只在比對時用，不改寫正文。**
3. **build 會吃掉譯文**：`ndl_data/{slug}/secN.json` 同時是 build 的產出與翻譯的
   checkpoint（`src` 由 build 寫、`zh` 由 uchimura_auto 填），修完 OCR 再 build
   一次會把 `zh` 清空。→ `has_translations()` 擋下，要重做得明確加 `--force`。
4. **跨頁要切開再 OCR**：整張跨頁丟進去等於每頁只剩一半解析度。
   `split_spread_boxes()` 切左右頁，**右半頁先讀**（日文直書右起）。
   順序反了整本文意會倒著接，而且每頁單獨看都正常。

### ⚠️ OCR 逐字精度：還沒精修

Gemini 讀得出來，但不是逐字無誤。只抽驗影像 3 一頁就抓到**兩個會改變語意的錯**
（已對照原圖修在 checkpoint 上，改 checkpoint 而非產出，重建才不會跑掉）：

| OCR | 原書 | 差別 |
|---|---|---|
| 最も**歡ばしい**ことである | 最も**歎かはしい**ことである | 可喜 ↔ 可歎，**意思相反** |
| 現在の**新興**教會 | 現在の**新教**教會 | 新興的教會 ↔ 新教（Protestant） |

一頁兩個，全書 18 頁 —— **其餘各頁尚未逐頁對照原圖**。這本目前是「可讀」不是
「精修」，日後要精修就逐頁調 IIIF 影像與 `ocr-gemini/*.txt` 對讀。
