# NDL デジタルコレクション 取源管線

無教會譜系與賀川豐彥那批戰前著作是公有領域，卻**不在青空文庫、也不在 libgen**
——只有國立國會圖書館的掃描本。這一檔記管線；書目與版權判斷見
[mukyokai_collected_works.md](mukyokai_collected_works.md)。

> **這份文件的順序是刻意的**：現行作法在前，走過的冤枉路在最後一節。
> 中間那些「用視覺模型 OCR 掃描影像」的作法**已經作廢**，別照著做。

---

## 一、判公開範圍：只有一個可靠辦法

    curl -s -o /dev/null -w "%{http_code}" https://dl.ndl.go.jp/api/iiif/{pid}/manifest.json
    # 200 ＝ インターネット公開（可用）
    # 404 ＝ 館內限定／個人送信（不可用）

書誌 metadata **不帶**這個欄位，別想從目錄判斷。
「圖書館‧個人送信」看起來可用，但**居住在日本境外者不能使用**，不算。
不要繞過存取控制。

## 二、取源：NDL 官方 OCR（★唯一該用的方法）

    https://lab.ndl.go.jp/dl/api/book/layouttext/{pid}     # 帶版面結構的 XML（ZIP）★首選
    https://lab.ndl.go.jp/dl/api/book/fulltext-json/{pid}  # 平鋪全文＋逐字座標
    https://lab.ndl.go.jp/dl/api/book/{pid}                # 書誌＋目次（分章靠它）

🚨 **端點是 `/book/layouttext/{pid}`，不是 `/book/{pid}/layouttext`。**
猜錯路徑會回 **SPA 殼（HTTP 200 但內容是 HTML）**——「200 不代表存在」，
跟 BDCC 的 500 是同一種陷阱。判斷端點在不在，看 `content_type` 不要看狀態碼。

### 準確度：NDL 官方 完勝視覺模型

拿原圖逐字比對（畔上《無教會主義》影像 4）：

| 位置 | Gemini Vision | NDL 官方 |
|---|---|---|
| 敎派**別**を無視 | 漏「別」 | ✅ |
| 加**へ**て | 加えて（假名改新式） | ✅ |
| 無敎**會的**精神 | 無敎**的の**精神 | ✅ |
| 保**續** | 保持 | ✅ |
| 以上**に精神**である | 以上は精である | ✅ |
| 人々**の**間に**一つ**の | 人々は間につの | ✅ |

**Gemini 錯的每一處 NDL 都對。** 視覺模型只留一個用途：補 `〓`（見下）。

### layouttext XML 怎麼讀

每行一個 `<LINE>`，帶 `ORDER`（全域閱讀順序）、`X`/`Y`（直排欄位座標）、
`TYPE`（本文／タイトル本文／ノンブル／柱／注）、`CONF`。

- **一定要照 `ORDER` 排**，不能照 XML 出現順序——TEXTBLOCK 是按版面區塊分的。
- **段落靠首行縮排還原**：同段各行的 Y（欄頂）齊平，新段落第一行低一個字
  （約 45px，門檻取 35px）。🚨 只有**第一行**縮排，續行回到欄頂。
- **章名（タイトル本文）要斷段**，**頁碼與柱不可斷段**——它們只是版面裝飾，
  夾在行序中間，斷了會把一段切成兩半。
- 章名本身別用版面那一行：常常亂序（「第二　起源」讀成「第二 源 起」）。
  章名用 NDL 目次 API。

## 三、🚨 `〓` ——最容易出錯的一步

NDL 把字集外的舊字體印成 `〓`（各書 300–900 處）。**它不是固定同一個字。**

### 這裡曾經有一個錯誤的設計，務必別走回去

原本的作法是「`〓` 一律當**敎**」。畔上兩本沒出事，**那是運氣不是設計**——
它們的 `〓` 碰巧幾乎全是敎。賀川《キリスト山上の垂訓》立刻打臉：

- 有一章講馬太五13「汝らは地の**鹽**なり」→ **整章的鹽變成敎**
- `心の淸き者` → `心の敎きもの`（八福）
- `斷食` → `斷敎`
- 漢文訓讀的八福也一併改掉

### 現行作法：語境錨定，補不出來就留著

`ndl_build.PLACEHOLDER_RULES` 只在**詞形明確**時補，其餘留 `〓`。
**看得見的未解遠好過看不見的錯。**

至今判讀出來的字形叢集（都是實際上下文推出來的，不是猜的）：

| 字 | 語境 |
|---|---|
| 敎 | 宗敎／基督敎／敎會／敎派／敎育／說敎／敎授／敎養／儒敎／新敎／舊敎／敎へ |
| 鹽 | 地の鹽／鹽もし效力／之に鹽すべき／鹽の層 |
| 鄕 | 故鄕タルソ／同鄕の人／鄕黨 |
| 樸 | **單純樸素**（這條定案，連帶 純樸なる泉／原始の純樸） |
| 熱 | 熱心と努力／この熱情／その熱き心／熱誠 |
| 淸 | 澄みて淸く／魂の淸き／莊嚴淸純／みなもとが淸くも |
| 硏 | 聖書之硏究 |
| 々〳〵 | 益々／愈々／屢々／もと〳〵／たま〳〵／まざ〳〵 |

### 兩個補 `〓` 的辦法，優先序不可顛倒

1. **拿第二份 OCR 逐字對齊**（`fill_placeholders`）——**驗證過的**。
   《無教會主義》就是這樣做到 `〓`＝0。代價是要跑一次視覺模型 OCR
   （每頁兩個半頁，103 頁的書＝206 次請求，超過日額度要分兩天）。
2. **上下文規則**（`resolve_ndl_placeholders`）——**統計推論**。

🚨 順序不能顛倒：先跑規則會把本來能驗證的位置也變成推論。

### 覆核機制：印**相異上下文**而不是次數

`ndl_official_text.py` 會列出規則動過的相異語境。
**310 次沒人看得完、277 種看得完**——鹽那件事就是這樣才發現的。
每次跑完掃一眼有沒有不像的。

## 四、🚨 人工更正一定要存成資料

`ocr-ndl/*.txt` 是**產出**不是原始資料。直接在上面手改，下一次重生就整批消失，
**而且重生完一切看起來正常**——章數對、字數對、canary 過，只有你逐字改過的
地方默默變回亂碼。真的踩到過。

一律寫進 `scripts/ndl_corrections.py`，由 `ndl_official_text.py` 重生後自動重套。
每條都要填**依據**欄（日後有人問憑什麼改，答案要在檔案裡）。
🚨 刪除型更正（`good` 為空字串）不能用 `good in t` 判斷已完成——空字串永遠 in。

## 五、分章的五個坑（都修好了，但要知道為什麼）

1. **章名之前的段落屬於前一章**。章名行已被丟出正文，所以**不能靠字串比對找章名**
   ——找不到就整頁保留，新章從前章的句子中間開始。要用 `_titles.json` 的版面位置切。
   ⚠️ 這個修法我曾經只寫一半（`section_payload` 會用但 `build_sections` 沒傳），
   等於沒修。
2. **多章共用同一張起始影像**（章題＋首節同頁；48 章的書有 16 章如此）。
   每章要取**自己那一個**標記，不能都拿第一個。
3. **標記不足時**（版面只認出一個章名但索引說有兩章）：該頁歸前一章，
   後一章從下一頁開始。🚨 **重複比錯位更糟**——讀者看到同一段兩次卻看不出異狀。
4. **目次跨頁**：NDL 索引只標第一頁。48 章的目次排在影像 7–8，
   單頁各 44%（低於 canary 門檻被擋）、兩頁合起來 85%。用 `toc_ratio_spanning`。
5. **後付會被當成正文翻進去**：目次通常沒有「奧付」這條，末章一路吃到書末，
   把版權頁與**出版社的書籍廣告**都翻進去。
   - 頁層級：`is_body_page()`＝本文行夠多**且**滿欄率夠高。正文頁 ≥0.87、
     奧付與廣告頁 ≤0.07。🚨 只看滿欄率會被行數極少的頁騙過（2 行本文、
     1 行滿欄＝0.50 剛好過關）。
   - 過渡頁（正文在該頁結束、廣告從同頁接著排）：`body_lines_before_layout_break()`
     ——直排欄位 X 等距遞減，廣告另起欄組會出現遠大於欄距的跳躍**且**字級變小。
     兩個訊號要同時成立才切：只看欄高會砍掉段末短行，只看 X 跳躍會砍掉跨欄插圖。

## 六、🚨 振り仮名（ruby）會把整行打散

NDL **沒有**把 ruby 另外標 TYPE，全混在「本文」裡，擋不掉。

    原文 こゝにかのセラピムのひとり鉗をもて壇の上より取りたる熱炭を…
    OCR  ことかのとろよろのひとる如をそて項の上よ取數な子に授と小麥

`garbled_lines()` 靠**字數對欄高的密度**偵測（亂掉的行會少一截字）。
全書 1,761 行只 3 行中鏢。
🚨 這只是**線索不是判準**：目次、版權頁那種寬鬆排版也會被撈進來，
撈出來的每一行都要回頭看原圖才能確認。

🚨 盤點的四個坑（前兩個會靜默回 0 筆，跟「真的沒有」長得一模一樣）：

1. 🚨 **字形送錯就 0 筆**。查「矢內原忠雄」得 0、查「矢内原忠雄」得 41 ——
   差別只在舊字體 內／新字體 内。交接的 9 部就是這樣來的。NDL 作者欄多半是
   新字體，但**兩種都有**（賀川舊字體那一輪多撈出 44 個 pid），所以現在預設
   兩種字形都查再合併，`--strict` 可關掉。**新增作者若回 0，先確認字形再下結論。**
2. `/dl/api/book/search?keyword=` 是**全文檢索**，關鍵詞出現在別人書的內文也會回來
   （查「畔上賢造」445 筆，實際著作 27 部；塚本虎二 159 筆實際 0 部）。
   一定要再用 `responsibility` 過濾。
3. 作者欄格式不一（`畔上賢造 [著]`／`カーライル 著||畔上賢造 訳`／`藤井, 武, 1888-1930`），
   比對前空白與逗號都要去掉，否則必然 0 筆。
4. 🚨 **一個 pid 是一個版次，不是一部作品**。《死線を越えて》佔 5 個 pid、
   《キリスト山上の垂訓》4 個、《愛の科学》3 個。拿 pid 數當「幾部著作」會灌水
   ——賀川 136 個 pid 只對應 89 個自著品種，其餘是異版與編／譯／合著。
   store 的書目是品種層級，比對前要先按書名歸併，年份取**初版**。

### 🚨 譯文欄裡放著日文原文（2026-09-09 掃出 160 段）

中文欄位排著日文，reader 照排，頁面完全正常。分佈：

| 書 | 滲漏／可譯段 | 比例 |
|---|---|---|
| 矢內原《帝國主義下的台灣》 | 72／458 | 15.7% |
| 矢內原《基督教入門》 | 38／490 | 7.8% |

| 賀川《垂訓》 | 6／170 | 3.5% |

另有 7 段是引擎**沒翻，改用對話語氣回話**：「我已準備好進行翻譯。請提供日文原文」。
那句被原樣存成譯文，而且因為排在段首還變成**章節標題**
（`chapter_path` 長成「時論與信仰 · 我已準備」）。高發於原文只剩殘片時
（只有「１」或「である。」，引擎合理地要求補完整）。

兩道防呆都加在管線裡了：

- `uchimura_build.strip_meta_reply`：判元回覆要**語氣詞＋任務詞同時成立**。
  只看語氣會誤殺正文（「我已準備妥當，要往耶路撒冷去」整句被丟掉過）；
  切點取開頭數句裡**最後**一句元回覆，逐句一碰到沒語氣詞的解釋
  （「這似乎是片段。」）就收手，會把後面真正的譯文一起丟掉。
- `uchimura_auto._kana_leak`：譯完檢查譯文有沒有假名（中文正文不會有，
  判準很乾淨），有就換 key 再試一次，還有就**留白**。
  留白比硬翻好——reader 端未填的段落顯示原文，讀者看得出那裡沒翻。

清舊資料用 `--redo-matching '[ぁ-ゟ゠-ヿ]'` 把中鏢段落設回 `None`，再 `--run-queue`。

### 🚨 章名那一層要單獨檢查（正文乾淨不代表章名乾淨）

同一批書，正文全部處理完之後線上還有 110 段夾日文——**全在章名行**。
章名有三種壞法，共通點是欄位都有值、格式都正確：

| 壞法 | 長相 | 從哪來 |
|---|---|---|
| 完全沒翻 | `## 第一章　宗敎の個人性・世界性・民族性` | `ndl_official_text` 把 NDL 目次的**日文**標題寫進 `title_zh`，管線看到有值就跳過翻譯 |
| 原標題沒剝乾淨 | `## 門をたたけ 叩門吧` | 引擎把原標題連著譯文一起吐回來 |
| 只翻一半 | `## ３　富める青年――不捨棄之人` | 引擎中途切換語言 |
| 多一截標記 | `## 二　耶穌的聖召` 變成 `## ## …` | `clean_zh_output` 刻意放行 `## ` 開頭（正文的內嵌小標要留著），那條規則走到章名這一層就多出標記 |

判準統一成**中文章名不該有假名**（跟正文同一把尺），三種壞法一次涵蓋。
`title_zh` 有值不代表翻過——這是本輪第四個「欄位正確但內容錯」的實例。

### 覆核一定要打 DB，不能只看本機檔

本機 `sec*.json` 乾淨、`--build-only --upload` 印「✓ row + previews」，
線上仍可能是錯的：撞號那次就是本機對、DB 錯。而且上架分兩步
（R2 推檔＋`ebooks` patch），第二步撞到連線重置時，翻譯與 R2 都成功、
只有資料列沒更新，log 卻報中止。**跑完一定回頭查 `ebook_chunks` 的實際內容**：
每本的段數、夾日文段數、元回覆段數、章名帶標記段數。

工程上因此加了兩條：上架失敗要能重試（連線重置不是內容問題），
以及跑完的驗收看**產出**（DB 內容）不看 log 有沒有印完成。

## 十、走過的冤枉路（**別再走一次**）

### ⛔⛔ Haiku Vision 在這批材料上會編造內容

使用者明確授權後跑過，結果比「跑不動」更糟：**吐出通順但整段虛構的日文。**

| | 內容 |
|---|---|
| 原圖真值 | 近頃「無教會主義」といふことが、日本の基督教界の一つの大きな問題となつてきた… |
| Haiku | 宗教と「無教會主義」と称することは、日本の基督教發展の二つの大きな問題であつた… |

作者名從「畔上賢造」變成「昭上賢造」「卍上賢造」「唵上賢造」（每次不同），
第一次跑甚至憑空生出一份**完全不存在的目次**（頁碼到 175，而全書只有 18 張影像）。

排除過的變因，**都不是原因**：解析度（1800→3575px）、跨頁沒切開、
prompt 太鬆（改嚴格逐字 prompt **更差**）。
失敗模式是**部分錨定的編造**：讀到零星字詞再用通順日文把中間補起來。

### ⛔ 視覺模型 OCR 整條路線已作廢

兩次獨立 Gemini 互比有 **271 處分歧**，逐字精度做不出可用的版本。
現在只留一個用途：補 `〓`。

### 🚨 two-strike 的語意曾經寫錯

`ocr_page()` 把「兩次連續 429 就退」實作成「試兩把 key 就放棄」，
而本機有 **7 把 key**。我因此誤判「今天沒額度」，才繞去試 Haiku。
**判斷沒額度之前先確認所有 key 都試過。**
（Gemini 日額度在台灣時間 15:00／太平洋 00:00 重置。）

### 仍然有效的兩道閘

- **`toc_match_ratio()` 目次 canary**：目次頁的內容本來就從 NDL API 知道，
  拿它驗 OCR 有沒有在讀圖。對 Haiku 那批實測**對上 0%**，成功擋下。
- **`refuse_empty_build()`**：所有 section 都沒正文就拒絕寫檔，
  免得產出結構正確、目錄齊全、每章卻沒有字的 `secN.json`。
