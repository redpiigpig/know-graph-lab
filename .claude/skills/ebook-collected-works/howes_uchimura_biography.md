### 「最權威」要分兩邊講（別再把豪斯說成唯一權威）

豪斯是**英文世界的定本**，這點沒有競爭者。但日本學界的權威不在他身上，而且
**豪斯自己在書裡就講明了**：致謝裡他稱**鈴木範久是「日本研究內村的第一人」
（Japan's preeminent scholar on Uchimura）**，說鈴木回答了他無數問題、還借出自藏
照片；第十五章他稱**政池仁為「內村的傳記作者」，並註明政池本人就是門下重要弟子**。

豪斯是外國人，但不是圈外人——序言裡他自陳：二戰被海軍日語學校捲入、戰後在盟軍佔領
下的東京；1951 年在哥大找題目時，中澤洽樹建議他寫內村（當時英文學界關於內村的資料
只有 Sansom 書裡的一個註腳）；到日本後，**東大的指導教授是時任總長的矢內原忠雄親自
指派**，**家永三郎**教他思想史的文獻分析。他是被無教會／東大那一圈人帶進來的。

這對中文讀者反而是優勢（他預設讀者不懂日本脈絡，該解釋的都解釋了），但要記得他偏
思想史加心理詮釋，視角也是那個圈子帶出來的，不完全中立。

**沒有任何一本內村傳記有中譯本**（中文世界只有內村本人著作的中譯）。REFERENCE-first
（[[feedback_collected_works_reference_first]]）走完是「查無」，所以自譯。

⚠️ **本書仍在著作權內**。私人站沿用 [[feedback_jung_nonpd_english_first]] 的姿態
（榮格 Hull 英譯同樣非 PD），但這一點與前兩波（內村本人著作全球公有領域）性質不同，
別把「內村＝PD」的結論套到這一本上。

## 原生 PDF 的分段：靠版面幾何，不是靠空行

這本是 Acrobat Distiller 出的原生 PDF，**有真的文字層，不需要 OCR**——但也因此
`get_text()` 出來是一行一行的，段落界線不在文字裡而在版面上。四個量測到的常數：

| 訊號 | 值 | 用途 |
|---|---|---|
| 正文行 x0 | 36.7 | 續行 |
| 段落首行 x0 | 45.7 | **縮排＝新段落**（區間 43.0–47.0，不是門檻） |
| 懸掛縮排續行 x0 | 48.7 | 編號清單的續行——**比首行還深，意思卻相反** |
| 正文字級 | 9.0 | — |
| 引文區塊字級 | 8.5 | 字級變化＝引文起訖，段前加 `> ` |
| 書眉字級 | 8.0（y≈36） | 丟 |
| 章名字級 | 18.0 | 丟（章名我們自己給繁中的） |
| 「This page intentionally left blank」 | 12.0 | 丟 |
| 尾註號 | superscript span（flags bit 0，字級 5.2） | **丟** |

三個坑：

1. **尾註號一定要在 span 層丟掉**。它跟正文同一行，不丟的話 `majority.14 There`
   會被翻成「多數。14 還有更多」——引擎會把裸數字當年份或數量譯出來。判準用
   PyMuPDF 的 `flags & 1`（superscript），不要用字級（字級 5.2 太貼近其他小字）。
2. **章名區塊在 PDF 裡不一定排在正文之前**。第 36 頁的章名 block 編號是 2、正文是
   0 和 1，照 block 順序讀會把章名插進頁面中段。`page_lines` 一律先按 y 再按 x 排。
3. **懸掛縮排比段落首行縮排還深，意思卻相反**。編號清單（第九章那份 précis）的
   首行在 36.7、續行在 48.7。原本寫「x0 ≥ 43 就斷段」，於是整段清單被炸成一行一段
   ——**譯文那頭才發現**：引擎回「您提供的原文似乎不完整（"nese who want to…"）」。
   改成區間 43.0–47.0 之後 1,582 段 → 1,442 段，以小寫字母開頭的段落 83 → 5。
   另有六十處字型對到 U+0001 的裝飾字元要濾掉。
4. **連續引文段落之間沒有縮排可分**（引文行 x0 全是 46），會黏成一大段——最長的一段
   近九千字。`split_long` 按句界切開，`> ` 標記每一片都要帶著；引擎偶爾會把標記吃掉，
   `make_engine` 在輸出端補回來。

## 🚨 專名漂移：一個人被翻成四個名字（2026-09-07 修畢）

使用者讀出來的問題：**內村的元配在譯文裡有好幾個名字**。查證後不只她一個，
而且不全是「不統一」，有兩筆是**事實錯誤**。這是 [[feedback_reader_silent_failures]]
最典型的一種——每一頁都通順、什麼都沒壞、驗證腳本全綠，只有拿英文原文逐段
交叉比對才看得出來。

| 英文（全書寫法一致） | 中譯變體 | 定名 | 性質 |
|---|---|---|---|
| `Take` | 武子 19／武江 5／武惠 2 | **武**（淺田武） | 同一人四種寫法 |
| `Yûshi` | 有島雄士 7／雄士 1／雄志 5 | **祐之** | ⚠️ 事實錯誤，見下 |
| `Asada Nobu` | 淺田延子／延子 | **淺田信** | ⚠️ 名字譯錯 |
| `Parmalee` | 帕馬利 7／帕邁利 2／帕美利 4 | **帕瑪利** | 音譯不統一 |
| `Gundert` | 貢德爾特 4／根德特 4 | **貢德特** | 音譯不統一 |
| `Ruth` | 露絲 14／路得記 11／路得 4 | 女兒＝**露絲**、書卷＝**路得記** | ✅ 本來就對，別「修」它 |

**這裡最該記住的一件事**：`Ruth` 那一列的分歧是**對的**——內村的女兒ルツ子與
《路得記》在英文裡同一個字，中文本來就該分開。所以規則不是「同一個英文詞一定
對同一個中文詞」，而是**同一個指稱對象一個名字**。動手前先分清楚是哪一種。

### 兩筆事實錯誤（不是風格問題）

- **`Yûshi` → 有島雄士**：內村的兒子是 **內村祐之**（1897–1980，精神科醫師、
  日本職棒 commissioner）。「有島」是隔壁段落 **有島武郎**（Arishima Takeo,
  1878–1923，同為內村門下）的姓，被翻譯借去用了。全書 `有島` 出現 27 次，
  其中 **20 次是真的有島武郎**，只有 7 次是污染——**整批取代會毀掉一個真實人物**。
  這正是 [[feedback_dynasty_empire_naming]]「整批取代會改到人名」的同一個坑。
- **`Asada Nobu` → 淺田延子**：長女是 **浅田ノブ**（1885–1967，後為日永信子），
  「延子」憑空生出來的。

### 定名依據

家族成員一律以日文正式名為準（ja.wikipedia 內村鑑三／內村祐之）。片假名女性名
依使用者 2026-09-07 定調走**漢字定名**：タケ→武、ノブ→信、ルツ子→露絲子。
**但 ノブ 一律寫全名「淺田信」、不寫單字「信」**——中文的「信」是書信／信仰，
單獨當人名讀不出來（原文那一段偏偏正在講她寄來的信）。

`Yûshi` 用**裸名 祐之**不加姓：英文全書都是裸名（首次登場即 “his son Yûshi”），
依使用者「英語不同才反映不同」的原則，英文沒加姓中文也不加。加了姓那一段會變成
六個「內村祐之」連發，很難讀。

### 工具：`scripts/name_lock.py`（+ `scripts/tests/test_name_lock.py` 14 例）

    python scripts/name_lock.py            # 只報告
    python scripts/name_lock.py --apply    # 寫回 JSON
    python scripts/name_lock.py --audit    # 改完驗殘留（0 才算過）

**核心規矩只有一條——有英文佐證才動手**：某個中文變體要被改寫，該段的英文原文
必須真的提到那個人（`Lock.en` 那條 regex）。這道閘就是有島武郎沒被毀掉的原因。
替換一律**長的先換**，否則「延子」會把「淺田延子」切成兩半。

跑完 62 處、`--audit` 殘留 0，已 `--build-only --upload` 重推（152 chunks）。
**新卷翻完一律先跑這支再上架**；換一本書就加一組 `Lock`。

### 🚨 Gundert 六種寫法：一個關於「怎麼找變體」的教訓

我找這個名字的變體找了三輪，每一輪都以為找完了：

1. 第一輪拿 `貢／昆／根` **猜首字**去撈 → 抓到三種，漏了 `岡德特`、`古德特`（首字全不同）。
2. 第二輪改從**共同尾字「德特」反查** → 抓到那兩種，卻漏了 `格恩德爾特`
   （它的尾是「德爾特」，連共同尾字都不一樣）。
3. 第三輪是掃日文字形時**偶然**撞見的。

**結論：不要從中譯自己找規律。**可靠的做法是拿查得到的本名（人物辭典、維基、
store 既有 hub）去對每一段的英文，反向確認中譯有沒有寫對。從譯文端找變體，
你永遠不知道還有第幾種。
