## 🚨 安全：頁面有鎖不等於資料有鎖

2026-09-02 使用者要放一批「勿外傳」的檔案，說「我的網站有密碼」。實測後發現
**兩層假設都是錯的**，兩個都不會報錯：

1. **API 沒有驗證。** 頁面的 `middleware: 'auth'` 只擋頁面。未登入直接打
   `/api/research-data/*` 九支端點全部回 **HTTP 200 連同全文**。
   已補 `requireAdmin`（`server/utils/auth-helper.ts`，照片那批 API 早就在用）。
   前端 `$fetch` 要跟著改 `authedFetch`，否則頁面全壞。
   🚨 `<a href="/api/…&download=1">` 這種直連**帶不了 Authorization header**，
   端點加驗證後會 401 —— 改用 `authedDownload()`（取 blob 再觸發下載）。
2. **repo 是公開的**（`github.com/redpiigpig/know-graph-lab`，visibility=public）。
   把全文放進 `public/content/` 就等於公開流傳，而且 git 歷史刪不掉。
   非公開材料一律：**全文上 R2（`research-private/`），repo 只留書目層**，
   由掛 `requireAdmin` 的端點供應。

放非公開材料前，三層都要實測過：
```
頁面 → 302 導登入 ｜ API → 401 ｜ R2 未簽名 GET → 400（桶無公開讀取）
提交前掃 staged diff：密碼、被監控者姓名、堂號皆 0 次
```

🚨 **檔案局查無「捕鼠案」是對的——它在國史館**，兩個館要分開查。

  證據：目次那列出來是「31｜30｜29｜28｜27｜**次目**」——數字遞減且「次目」正是
  「目次」反過來。每列都要 `reversed()`
- 🚨 **格內也是直排**，文字逐字換行（`中
華
民
國`），要清掉空白才併得回。
  修完單字元行從 15% 降到 1%
- `位單轉移`／`位單案原` 這種格內橫排右至左的欄位名**原樣保留**——需要語意判斷，

## 各站台的解析陷阱

**tcnn.org.tw（教會公報新聞網）** `scripts/pct_tcnn.py`
WordPress 且 REST API 未關，逐篇連全文一起給，最省事。以「年」為窗口分頁避開深分頁問題。全文按年打包 JSONL 放 R2；**逐年篇目清單約 6 MB 不進 repo**，由 API 直接讀 R2 供應，否則每次重跑都整批改寫。

**gospel.pct.org.tw（新使者）** `scripts/pct_newmessenger.py --mag`
同一套舊 ASP.NET 版面用 strTID 掛多刊：1 新使者、4 女宣、6 事工說明書。三個坑：
- 內文固定在 `<td id="Zoom">`（其他選擇器都會抓到分享表單）
- **欄目那格的 class 導覽列也在用**，取第一個會拿到空的導覽格，要從題名往上找
- **期名只在文章頁的麵包屑上**，目次頁反而沒有

**www.pct.org.tw（總會重要文獻）** `scripts/pct_documents.py`
🚨 **DocID 是補零三位**（`DocID=001`）；不補零的 `1` 一律回 500，1971–2005 的早期文獻會整批漏掉——三大聲明就在那個範圍。年份取自頁面 `<title>` 的「1971重要文獻」段，比從內文猜可靠。信仰告白不走 DocID，另在 `ab_faith.aspx`（台語漢字／華語／英語三版並列），用 `--static` 收。

**ct.org.tw（基督教論壇報）** `scripts/ct_forum.py`
自寫 PHP，四個坑：
- **文章 ID 不能遞增窮舉**——無效 ID 一律回同一張預設頁（不是 404），只能從分類列表逐頁取
- **日期與作者只在列表頁上**，單篇頁沒有；列表階段就要記下來，否則語料層排不出年表。
  列表頁有**兩種版型**都要收：`div.card`（分類本體，一頁 12 篇，日期在 `span.date`、作者在 `span.author`）
  與 `div.caption`（頁首輪播 6 篇，**每一頁都一樣**，三項擠在 `div.description`）。12+6=18＝`PER_PAGE`。
  兩種的作者都是「刊名連結後面那段純文字」（本報訊／記者梁敬彥／編譯余友梅…），要先把 `<a>` 拆掉再取
- 🚨 **`harvest()` 用 `setdefault` 合併，既有的列永遠不會被更新**。所以「改了 parser 再重跑」
  對已收的兩萬多列一點作用都沒有——補欄位得改成「只填空欄」的合併，
  而且**絕不能蓋掉 `chars`**（那是 `--process` 算出來的，列表頁沒有）
- 署名同一人有多種寫法（`記者梁敬彥`／`梁敬彥`／`記者 梁敬彥`），332 種遠少於 332 個人。
  這是報社署名本身不統一，**照原樣存不要自動正規化**，要合併得人工定奪
- 🚨 **翻頁的終止條件只能看「這一頁還是不是真的列表頁」**（ID 集合與第一頁相同＝已翻過頭）。用「有沒有新文章」判斷，續跑時前幾頁本來就都收過了，會一開頁就誤判到底（社論言論一類因此只抓到 36 篇，修好後 524 篇）
- 🚨 **harvest 每跑完一個分類就覆寫 HARVEST 檔**，中途 kill 掉會把先前較完整的清單覆蓋成半成品（踩過一次：完整的 23,713 篇被覆蓋成只跑到第 10 類的 10,368 篇）。要中斷就等它跑完一輪，或先備份 `C:/tmp/ct_forum.json`
- 🚨 **`--process` 一輪跑完就結束、不會自動接續**——每輪只處理當時清單裡尚未入庫的部分，看到「新增 N 篇」的結尾就是一輪結束，要再下一次
- 🚨 **中斷 `--process` 會留下缺 `chars` 的篇目**。那批全文其實已經上了 R2，只是還沒寫回 harvest；
  重跑 `--process` 只會因為「R2 已有」把它們跳過，字數就一路少算（踩過一次，400 篇少算約 65 萬字）。
  用 `--backfill-chars` 從 R2 讀回長度補上，再 `--publish`
- 🚨 **專題頁判別不能只看子連結數**——每篇文章頁側欄本來就固定掛 8–9 條「相關文章」，門檻設 6 會誤殺 8,960 篇正常報導。專題頁的特徵是子連結明顯多於側欄常數且正文極短（現用 ≥14 且 <1200 字）

**白話字教會公報（1885–1969）** `scripts/pct_poj.py`
補的是 tcnn（2010-12 起）之前那八十四年——長老教會機關報從《台南府城教會報》到
《台灣教會公報》，全以白話字書寫，1969 年才改出華文。論文第二章與第四章前段
（黃彰輝那一代之前）的公共發言只能從這裡看。
來源是師大台文所「台灣白話字文獻館」的 GitHub 鏡像 `Taiwanese-Corpus/Khin-hoan_2010_pojbh`
的 `pojbh.json`（23.5 MB，2,805 筆，其中 2,735 筆有全文）。每篇有**漢羅**與**台羅**兩種寫法。
- 🚨 **這是選輯不是全份**。中研院語言學研究所另有 1885–1969 逐頁掃描並輸入的完整閩語
  資料庫（數位典藏 `LAMINTX0008`，`ascdc.digitalarchives.tw/collection_3334386.html`），
  但那一頁只是藏品層級目錄（型式:合集、數量:1），**沒有任何下載**，管理權在語言所，
  要去信 `ilsecretariat@sinica.edu.tw` 談授權。不要把本批說成「教會公報全收了」
- 🚨 **只收文字不收圖片**。README 載明文字採 CC 授權，圖片另向台灣教會公報社、
  長老教會教會歷史委員會、真理大學牛津學堂、淡江中學校史館授權——不是我們的
- 🚨 **這批是白話字／漢羅台語，不是華語**。策展詞表那些華語詞（本色化／實況化…）
  對 `Kàu-hoē`、`kui-chèng` 一個都比不到，要進語料層得另立台語詞形，
  道理同日文那邊（「無教会」與「無教會」各自成詞，合併會互相污染）
- 按**十年**打包成 JSONL 上 R2，不逐篇一個小檔——論壇報那兩萬多個小檔讓語料層
  掃描慢了一個數量級，這是那次的教訓
- `pianho`（編號）2,805 筆全唯一，可直接當鍵；篇名一律 `漢字 [ Pe̍h-oē-jī ]`；
  日期只到「年/月」且有 17 筆寫「不詳」，**歸自己一桶不做內插**

**laijohn.com（賴永祥長老史料庫）** `scripts/laijohn_biographies.py`
靜態 Big5、無反爬，但站方是義務維護的個人史料庫，延遲放 0.5 秒。路徑 `/archives/pc/<姓>/<姓,名>/…` 本身帶人名代碼，不必解析頁面即可歸戶。**人名代碼要用站方的羅馬字拼法**（黃彰輝是 `Ng,ChiongHui` 不是 `Ng,Chhui`），猜錯會以為沒收到；用篇名反查較保險。宋泉盛不在本土信徒區（長年在海外）。

**無教會** `scripts/mukyokai_sources.py`（單件收錄）、`scripts/nonchurch_magazine.py`（《無境界者》整本）
以「運動」而非機構為單位。日文論著保留原題（`titleOriginal`）另附中譯，`--lang ja`。支援 .docx（宣言、創刊宗旨這類原生 Word 檔，走 zipfile 讀 document.xml，不必 OCR）。

## 國家檔案（檔案管理局）`scripts/archives_gov.py`

戒嚴時期國家如何處置宗教，證據不在報紙而在情治單位的公文裡。26 組查詢、**5,057 筆書目**，
其中 **528 筆可線上閱覽（可直接下載影像）**，其餘須向檔案局申請。

分區：長老教會 2,714（含三神與四人系譜與三個專案代號）／佛教 1,861／一貫道 417／衛理公會 65。
成果同時放 Drive `研究資料/國家檔案調閱/`（總表 txt ＋各區 json）——repo 那份是網站讀的，
Drive 那份才是使用者拿得到的。

**發現的重點**：黃彰輝 91、宋泉盛 28、**王憲治 83（調查局 73）**、黃伯和 49 —— 四人系譜全被監控；
高俊明 582（線上 157，含美麗島偵訊筆錄 388 頁、財產查封 295 頁）；南神 134 遠多於北神 43；
傳道法師 136；印順 4（含「可疑分子考管-印順和尚」與《佛法概論》查禁公文）。

- 🚨 **一律走 curl**。站方 WAF 認**客戶端指紋**不認 IP：Playwright 回一頁
  「The URL you requested has been blocked」而 HTTP 仍是 200（只看狀態碼會誤判成成功）；
  Python requests 連 TLS 握手都被拒；curl 同一時間正常。曾誤判成「IP 封鎖」而停跑一整天
- 🚨 **表單 35 個欄位要連同預設值一起送**。只挑幾個送，關鍵詞會被忽略而回傳整個資料庫
  （三個不同詞都回 4,847,628 筆）。用不相干的詞（鰻魚養殖 11 筆）當對照組驗證
- 🚨 **零結果與請求失敗必須分開回報**。查無資料回的是 187 KB 的表單頁、沒有「共為 N 筆」；
  有結果是 800 KB 以上。只回一個「?」會讓「查過確實沒有」與「抓壞了」混在一起
- 🚨 **每個欄位各用自己的樣式，不要共用一條「非貪婪＋前瞻」通式**。那種寫法兩頭都會錯：
  後面緊接標記時 `.{0,60}?` 會匹配成**空字串**（實測 56.8% 的檔號變空白，而檔號是申請調閱
  唯一必填的欄位），沒緊接時又會吃進隔壁的「檔案起訖日期」（1,636 筆被污染）
- 🚨 **「檢視全部案件」不是一筆檔案**，是同一筆的下層連結，不排除掉會灌水
- 🚨 **「已數位化」不等於「可以下載」**。影像檢視頁的按鈕是「下載全部影像／加入申請書」兩種：
  標「可線上閱覽」者真的能下載，標「須提出申請」者只能加入申請書
- **政治檔案篩選（QueryRange2）送出去沒有作用**，限與不限筆數完全相同，故不跑兩輪
- 檢索詞要用**當時公文的用語**：「印順和尚」有 4 筆而「釋印順」0 筆；
  昭慧法師則是「昭慧」17 筆全為同名者（曾／江／楊昭慧），「昭慧法師」「盧瓊昭」「弘誓」皆 0 筆
  ——這是查過而確實沒有，與沒查過是兩回事，要記下來

## 到館前要用的三份清單 `/research-data/pct/biblio`

三個分頁：華藝期刊書目（1,728 筆）、臺灣博碩士論文、臺灣記憶館藏（444 件，434 件附目次共 12,821 條）。
都只收書目，不取全文。

**華藝** `scripts/biblio_search.py`
搜尋是把一整包 JSON 塞進網址 queryString，結果頁 JS 渲染，故用 playwright。
結果頁有 `#Result_每頁顯示` 可切 50 筆，翻頁鍵在 `.page a`。上限 8 頁＝400 筆／組，
**撞到上限的組要標 `truncated`** 並顯示在頁面上——不標的話截斷會看起來像「這題目就這麼多」。

**臺灣博碩士論文** `scripts/thesis_ndltd.py`
🚨 **一組一組跑、每組存檔**。原本一次把 14 組丟給 node，跑完才回傳——撞到一小時逾時，
一整輪結果全丟。現在 `--search` 會跳過檔裡已有的組，可以直接重下續跑（`--force` 才重跑全部）。
🚨 **驗證碼是「流量觸發」的，不是常態掛著**——兩種先前的判定都只對了一半：
既不是「全站掛驗證碼、不可抓取」，也不是「首頁與檢索都沒有驗證碼」。
站方依**連線 IP** 計量，抓密了就跳出 `驗證碼檢查機制` 那一頁
（「由於目前系統使用人數眾多……敬請輸入畫面中的圖形驗證碼」），停一段時間才退掉。
2026-08-30 實測：`--search` 連跑 13 組全部撞上，14 組只有第 1 組是在冷卻前跑完的。
**不要繞過它**——那是站方為維持服務品質設的；只能放慢、隔開時段、分次跑。
腳本現在會先認出驗證碼並回報 `CAPTCHA：…`，不再只留一句 `#ALLFIELD` 選擇器逾時
（那會讓人誤以為是站方改版）。
🚨 **抓取失敗不寫入結果檔**。原本失敗也照樣存成 `count: 0`，在頁面上會長成
「這個題目沒有論文」，跟真的 0 筆分不出來——踩過一次，13 組全成空章節。
🚨 **截斷與否看站方自報的「檢索結果共 N 筆」，不要看翻了幾頁**。分頁鍵有時會在
同一頁上打轉，翻滿 8 頁、去重後只剩 8 筆，用 `pages > 8` 判就會標成截斷卻說不出
站上到底有多少。現在 JS 一併回傳 `total`，`truncated = total > 取回筆數`。
而且**博碩士論文那一欄原本根本沒顯示截斷標記**（華藝欄有、這欄漏了），
於是「8 筆」看起來就像「這題目就只有 8 篇論文」——正是本節開頭要防的那件事。

其餘三個坑：
- **預設只查「論文名稱」且模式「精準」**，多數複合詞回 0 筆 → 必須勾 `#ALLFIELD_不限欄位`
- **查詢模式不可選「模糊」**（`es1`）：它把詞拆成單字比對，「長老教會 公共神學」會撈回一整頁
  植物生理學論文。用預設的「精準」，詞間空白＝AND
- **「下一頁」是 `input[type=image][name=gonext]`**，沒有 value，用 `input[value="下一頁"]` 永遠抓不到，
  會靜默只取回第一頁；而且它要等結果頁渲染完才掛上，不等就誤判成「只有一頁」
記錄連結帶 session 代碼 `ccd=XXXX` 會過期，故只存書目欄位不存連結。

**臺灣記憶** `scripts/tm_presbyterian.py --list`（書目）／`--toc`（目次，需 playwright）
444 件全部 `DO_authorized=0`「不開放授權」，**只取書目與目次，不取數位影像**。
目次很有價值：帶原書頁碼（例「第十六回：一九○三年十月九日 頁149」），歷史檔案館庫房閉架、
每人每次限 10 件，到館前就靠目次挑件。
單件頁沒有「目次」標題也沒有專屬容器，目次夾在「`<頁次>/<總頁數>`」與「數位物件瀏覽」兩個標記之間，
只能用標記切；切不到就是這件沒有目次。已查過的記 `tocChecked`，沒目次的不必重查。

## 語料層的一條界線

國度復興報進語料層時**年份一律留空**。那批只有 Wayback 快照日、沒有發布日期
（三種欄位都驗過是站台固定值或快照日）。快照日是「發布日的上限」不是發布日，
拿它當年份會讓年代曲線**看起來成立而其實是假的**。

## Wayback 限流的樣子

🚨 **表現是「連線被拒」不是「回應變慢」**：`curl: (7) Failed to connect ... port 443`。
失敗只花 3 秒，所以單獨測一次多半正常，但迴圈裡大部分被拒、重試、再被拒，
五分鐘只成功 3 篇＝每篇 100 秒。**這種情況縮短延遲只會更慢**，方向要相反：
延遲 4s → 15s、連線被拒退避 30/60/90s、連續 12 次熔斷停手。
