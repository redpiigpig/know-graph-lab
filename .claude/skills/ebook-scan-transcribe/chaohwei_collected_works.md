## 全集不只專書：單篇文章那一條線

使用者定調（2026-09-10）：昭慧法師的全集要含**期刊論文、研討會論文、雜誌文章，
以及報刊上的採訪與專文**。關鍵事實是——**這些多半已經在站上**，只是散在
`/research-data` 各 collection 裡，全集那邊看不到。所以這條線做的是
**盤點與連結**，不重抓、不重存。

`scripts/chaohwei_articles.py` 跨 collection 撈，出成
`public/content/collected-works/chao-hwei-articles.json`，hub 的「單篇文章」區讀它
（獨立 JSON 而非塞進 `stores/collectedWorks.ts`——那支已經四萬多行）。

### 🚨 「她寫的」與「只是寫到她」是兩回事

教會公報那 42 篇全部是報導中提到她（致詞、與談、受訪）。只用名字比對會把
42 篇新聞全收成她的著作——而且看起來很像成功（數字漂亮、每一筆都真的提到她）。
`BYLINE_RE` 認的是署名樣式（`◎釋昭慧`、`文／昭慧法師`、`作者為…昭慧`）。

使用者認為公報有她的投書，但新聞網（tcnn.org.tw）上找不到。可能落在紙本
《台灣教會公報》而新聞網未收，或在 **2008–2010 那段沒有免費來源的缺口**
（[[project_pct_research_data]]）。待確認。

### 作者署名不一致

「釋昭慧」「昭慧法師」「昭慧」都有，英文是 Shih Chao-Hwei。查詢一律用「昭慧」
子字串；合著（頓號）與跨宗教對談（`古倫神父‧昭慧法師`）要先拆開才比得到。

## 兩本書的差異（為什麼 `scan_books.py` 要設定驅動）

|  | 心靈的交會 | 初期唯識思想 |
|---|---|---|
| 版式 | 橫排 | **直排**（轉錄一律出橫排純文字） |
| 2-up 半頁順序 | **下半頁在前**（b 在下、c 在上） | **上半頁在前**（130 在上、131 在下） |
| 頁碼 | 阿拉伯數字；前言 a–d、i–iii | 中文數字（一三〇），OCR 換算成 130 |
| 腳註 | 少（對談錄，全書個位數） | **多**，且**常跨頁**（`[^續]` 機制就是為它做的） |
| 掃描狀況 | 有 2 頁重掃、章末空白頁 5 處 | 有前手的**鉛筆畫線與眉批**，一律忽略 |
| 文體 | `dialogue`（段首 `〔辛格〕`／`〔昭慧〕`） | 論著（通用版面） |

半頁順序若寫死，整本頁序會兩兩顛倒，而**每一頁單獨看都正常**。
