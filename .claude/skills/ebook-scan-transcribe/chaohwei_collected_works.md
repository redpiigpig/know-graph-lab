## 🚨 頁末有註時，跨頁的句子接不起來（2026-09-15 修）

補完頁 48 才發現的：`stitch_pages` 原本寫著「前一段是註文時，下一頁正文不可接
上去」（`not is_note(out[-1][1])`）。但**頁末有註時，正文的續句被夾在註後面**，
於是只要一頁同時「正文斷在半句」又「有腳註」，下一頁的開頭就接不回去。

實測《初期唯識思想》**58 處**這樣斷開，而且斷在詞中間：

```
頁 7→8    …唯識學發展到圓熟階段，境 ┆ 界果的完整體系。
頁 47→48  …與實際有很大的差       ┆ 距，吾人必須看透語文…
頁 57→58  …某一大部分屬於認       ┆ 識論的問題…
頁 92→93  …當來下生龍華三會的彌    ┆ 勒菩薩…
```

版面上完全看不出來——兩段都通順，只是句子被切成兩半。**這正是掃描本最危險的
那一類錯。**

修法：往回**跳過註**，找最後一段正文來接；整頁都是註（接不到正文）才放棄。
`scripts/tests/test_chaohwei_build.py` 加兩例鎖住（會接、以及不該接時不接）。

⚠️ 這是 `chaohwei_build.py` 的共用碼，**兩本書都受影響**，所以兩本都重推了
Drive JSONL／R2／DB：《初期唯識思想》161,343→162,172 字（頁 48 約 800 字＋接縫
標記），《心靈的交會》115,228→115,468 字（純接縫）。

已寫進 hub 的 `sourceNote`，讀者看得到。要補得回頭找紙本重掃那兩處。

hub 的 works 照抄《心靈的交會》書末的「法界出版社出版圖書目錄」，**編號即該目錄
編號**（1001–1030）。⚠️ 該目錄**沒有出版年**，`yearSort` 暫用目錄編號排序，
**不可當出版年引用**；逐本取得版權頁後要補。這份目錄也只涵蓋法界出版社，
其他出版社的著作另計。

### 🚨 「她寫的」與「只是寫到她」是兩回事

教會公報那 42 篇全部是報導中提到她（致詞、與談、受訪）。只用名字比對會把
42 篇新聞全收成她的著作——而且看起來很像成功（數字漂亮、每一筆都真的提到她）。
`BYLINE_RE` 認的是署名樣式（`◎釋昭慧`、`文／昭慧法師`、`作者為…昭慧`）。

使用者認為公報有她的投書，但新聞網（tcnn.org.tw）上找不到。可能落在紙本
《台灣教會公報》而新聞網未收，或在 **2008–2010 那段沒有免費來源的缺口**
（[[project_pct_research_data]]）。待確認。

### 作者署名不一致

「釋昭慧」「昭慧法師」「昭慧」都有，英文是 Shih Chao-Hwei。查詢一律用「昭慧」
子字串；合著（頓號）與跨宗教對談（`古倫神父‧昭慧法師`）要先拆開才比得到。

## 兩本書的差異（為什麼 `scan_books.py` 要設定驅動）

|  | 心靈的交會 | 初期唯識思想 |
|---|---|---|
| 版式 | 橫排 | **直排**（轉錄一律出橫排純文字） |
| 2-up 半頁順序 | **下半頁在前**（b 在下、c 在上） | **上半頁在前**（130 在上、131 在下） |
| 頁碼 | 阿拉伯數字；前言 a–d、i–iii | 中文數字（一三〇），OCR 換算成 130 |
| 腳註 | 少（對談錄，全書個位數） | **多**，且**常跨頁**（`[^續]` 機制就是為它做的） |
| 掃描狀況 | 有 2 頁重掃、章末空白頁 5 處 | 有前手的**鉛筆畫線與眉批**，一律忽略 |
| 文體 | `dialogue`（段首 `〔辛格〕`／`〔昭慧〕`） | 論著（通用版面） |

半頁順序若寫死，整本頁序會兩兩顛倒，而**每一頁單獨看都正常**。
