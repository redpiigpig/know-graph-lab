## 一、別人是怎麼做的

查的方法很簡單但很有效：**用 `yt-dlp --print "%(description)s"` 把說明欄整段抓下來**，
製作名單與素材出處多半就寫在裡面。比看任何「十大推薦」的部落格可靠。

| 頻道 | 畫面怎麼來 | 證據 |
|---|---|---|
| **Veritasium** | 四條路並用：①四位動畫師手做（掛名）②付費 stock（Getty、Pond5）③NASA 各中心公有領域 ④**NCSA 超級電腦中心的科學視覺化**（宇宙學模擬算出來的，不是畫的也不是買的） | 說明欄原文 |
| **Linvo說宇宙** | 說明欄有八條學術引用，**影像來源一字未提**。中文科普圈普遍不標 | 三支影片實查 |
| **李永樂** | 一個人、黑板、粉筆，沒有動畫也沒有團隊 | 媒體報導 |
| **Cheap** | 早期用世紀帝國 2 遊戲畫面演戰役，後改免費素材；台北題材靠報時光等老照片庫；插畫外包（「圖／蓓蓓姊姊」） | 維基＋說明欄 |
| **臺灣吧** | 全部自己畫（原創 2D 動畫），沒有素材問題但最貴最慢 | — |
| **歷史哥** | 不做畫面，直播為主，編輯剪精選 | 說明欄 |
| **超粒方** | 有固定班底，說明欄逐支列「剪輯：geekybruce／腳本：Jon、麗芳」 | 說明欄 |
| **卢格杜努姆的奥古斯丁** | B 站 106 萬粉，法國留學專攻中世紀教會史，每支至少兩週考據、13–47 分鐘。**跟本專案最像的參照** | 二手＋說明欄實查 |

**歷史題材的共同處境是「沒有影像」**，各家解法就是各家風格：遊戲畫面／自畫動畫／
老照片／不做畫面。本專案的解法是無限黑板，屬於「自畫」那一類但成本低得多。

## 二、能拿的素材（依授權）

### 宇宙・太空
- 🟢 **NASA SVS**（`svs.gsfc.nasa.gov`）公有領域，部分項目有 4K ProRes 4444 帶 alpha；
  API：`/api/search/?search=nebula`（參數是 `search` 不是 `q`）
- 🟢 **images.nasa.gov** 14 萬筆，找 `~orig.mp4` 是最高畫質
- 🟡 **ESO / ESA-Hubble / ESA-Webb** CC BY 4.0，credit 不得縮寫或藏起來
- 🟢 **JangaFX 免費 VDB**（CC0 體積素材）＋ **Poly Haven** HDRI（CC0）＋ NASA 64K 星圖／16K 月球貼圖 → Blender 自算
- 🟢 **Video Copilot Orb**（AE 免費行星外掛）、**PremiumBeat Space Kit**（免費 40+ 太空素材）

### 台灣歷史影像
- 🟡 **國家文化記憶庫**（`tcmb.culture.tw`）——見下方「三」，**這是本專案自建素材庫的來源**
- 🔴 **臺灣舊照片資料庫**（台大圖書館，4.2 萬筆）——只授權「學術合理使用範圍內」下載，
  **再利用要另行申請**（tulcg@ntu.edu.tw）。當研究參考可以，當影片素材不行
- 💰 **報時光**（聯合報系）——商業授權服務，不是免費資源

### 免費影音圖庫
- 🟢 Pexels／Pixabay／Mixkit（Free License）：可商用免標示，禁原樣轉售
- **Videvo 已經不存在**（301 導向 Freepik，現名 Magnific，免費層要標示）

## 三、會咬人的條款

- 🚨 **SVS 影片的配樂常常不是公有領域**——官方 FAQ 明說要「without the associated
  audio tracks」。一律靜音使用。
- 🚨 **同一張哈伯／韋伯影像，NASA 側是公有領域（免標示），ESA 側是 CC BY 4.0（必須標示）。**
- 🚨 **esa.int 主站 ≠ esahubble**：主站預設禁商用，CC 的那部分還帶 ShareAlike 會傳染。
- 🚨 **SpaceEngine 本體版 EULA 寫明影片「not monetized in any way」**，營利要買 PRO
  （NT$2,210）並掛 `Produced in part with SpaceEngine PRO`。
- 🚨 **Envato Elements 禁止 as-is 使用**：拿一支素材配音效丟上 YouTube＝違約。
- 🚨 **Shutterstock 標準影片授權有 50 萬觀眾上限**，且禁 Broadcast／OTT。
- 🚨 **中國素材站：新CG儿 明文僅供學習交流、禁商用；摄图网 不續費舊影片就變侵權。**
- 🚨 **JAXA 與中國載人航天的官方影像禁商用／須事先核准**，不能比照 NASA。
- 🚨 **Content ID 假申訴在公有領域素材上非常猖獗**（NASA 官方頻道自己都被下架過）。
  下載當下就存來源網址、授權頁截圖與日期，申訴時直接貼。
  對照 [視覺中國黑洞事件]：連 CC BY 4.0 的 EHT 黑洞照都被拿去主張版權；
  2023 年星空攝影師戴建峰還被索賠自己拍的 173 張照片。**天文與星空影像是釣魚重災區。**

## 四、法律那條線（台灣）

著作權法 **§52**：「為報導、評論、教學、研究或其他正當目的之必要，得在合理範圍內，
**引用**已公開發表之著作」——關鍵是「引用」：你的論述要是主體。

**§65** 四款審酌基準：利用之目的及性質、著作之性質、**所利用之質量及其在整個著作
所占之比例**、**對著作潛在市場與現在價值之影響**。

**谷阿莫案的結局**：2017 年被五家片商提告，**沒走到判決**，2020 年 6 月和解、賠約
新台幣 100 萬元。真正該看的是後果——實查他主頻道近三支影片全是 48–52 分鐘的自製
訪談專題，**一支電影解說都沒有**。「X 分鐘看完電影」這個型態在台灣被這場官司終結了。

**本專案為什麼站得住**：解說是主體（倫理學＋比較神話學雙軸），預告片只佔 20%，
且只用片方公開發布的預告片、不碰盜版片源。這正是 §52「引用」的樣子。

中國那邊對照：《網絡短視頻內容審核標準細則（2021）》**第 93 條**明文禁止
「未經授權自行剪切、改編電影、電視劇……」，2021-04-09 更有 15 家協會＋53 家影視
公司＋三大平台聯合維權聲明。B 站影視解說是靠平台默許與片方合作在活。
