## 🚨 事件四個，時期四個，章五章

第二個時期佔兩章：尼西亞先**劃界**（第3章），那條界再在往後五百年**分流**成七個教系
（第4章）。劃界是事件的直接後果，分流是它的展開。使用者一度問「還是四個時期？」——
時期確實是四個，別把章數當時期數，也別為了對齊而把第3、4 章併成一章。

## 🚨 核心主張：每次事件之後，譜系單位就換一次

這是全書的骨幹，也是它與孔漢思典範論的差別所在。

| 事件 | 此後判斷「一支」的依據 | 譜系單位 |
|---|---|---|
| 起源 | 保存誰的記憶、經誰傳下 | 記憶的保存者（軌跡） |
| 正統化 | 屬哪個教座、認哪份信經、用哪種神聖語言 | 教座與宗主教集團（教系） |
| 改教 | 認信哪份文書、追溯哪位會祖 | 認信文書＋會祖（宗派） |
| 現代化 | 站哪個立場、參與哪個運動 | 立場與運動（陣營） |

**用後一段的單位讀前一段，會錯得很像對的**：用宗派讀二世紀是時代錯置；用教座讀十六
世紀之後會得出「新教沒有教會」；用宗派讀二十世紀會完全看不見福音派與普世運動。每一
章開頭都要重述該章所用的單位。

跨宗教適用時，四類事件（起源／正統化／改革／現代化）是通用的，差別在三個變項：
**位置、強度、內生或外生**。佛教不是模型的反例，是正統化事件弱且改革事件緊貼起源
事件；印度教的現代化事件回過頭去製造了起源事件的敘述。

## 🚨 方法論的立場：不是分工，是同一個動作

早期版本把紐曼與傅柯寫成分工（傅柯管描述、紐曼管評價），被使用者退回——那等於預設
解構與建構必須分屬兩人兩階段。

正確的立場是**把正統／異端從判準降格為現象**：這一步同時解構（正統失去不被觀察的
特權）與建構（多出「邊界的生成史」這個正面的研究對象）。文獻護欄是威廉斯的**肯定性
譜系**（vindicatory genealogy，指出一個東西有出身不等於指出它是假的）與庫普曼把傅柯式
批判理解為**問題化**（並論證它與規範性重建不衝突）。

## 🚨 這套方法不是原創，書裡要照實寫

使用者直接問過。五項核心工具都有明確前人：

* **典範分期**——孔漢思《基督宗教：本質、歷史與未來》用孔恩的典範論切六個宏觀典範
  （尼西亞、改教、啟蒙都切了）；博許《更新變化的宣教》把它用在宣教史，是這套框架在
  華語神學教育的主要流通管道。
* **軌跡**——羅賓遜與克斯特《穿越早期基督教的軌跡》（1971）；上游是包爾（1934）。
  ⚠️ 本書只採包爾命題的弱版本（正統化之前多條軌跡並存），不採強版本（異端在許多地區
  是原初形態）；混用兩者是這個領域最常見的失誤。
* **譜系學進宗教研究**——阿薩德《宗教的譜系》（1993），但他做的是「宗教」這個範疇的
  譜系，不是宗派的譜系。
* **宗派按家族分類**——梅爾頓《美國宗教百科全書》自 1979 年起的標準作法。
* **宗派歸併成「傳統」**——史廷斯蘭等人的 RELTRAD（2000），依宗派史、信條、普世組織
  隸屬三項歸併，是社會學那一側的標準方案；其「無法歸類」比例 1970 年 2%→2018 年 6.5%，
  是「宗派這個單位正在失效」的可測量證據。

剩下能主張的只有三點：把五者接成一張圖並指出接縫、把東方諸教會平等放進來、華語世界
空白。**不可以把「宗派譜系學」講成一門新學科。**

## 🚨 「宗派」這個詞在四種語言裡是四個隱喻

第1章第九節。這是全書最容易被忽略、但對譯名工作最有用的一節：

| 語言 | 詞 | 隱喻 | 問的問題 |
|---|---|---|---|
| 希臘文 | αἵρεσις | 選擇 | 你挑了哪一套？ |
| 拉丁文 | secta | 跟隨 | 你走在誰後面？ |
| 拉丁文 | denominatio | 換喻（修辭學術語！） | 這被叫作什麼？ |
| 英文 | denomination | 命名 | 你們自稱什麼？ |
| 漢語 | 宗派 | 血脈（宗＝尊祖廟） | 你是誰的後代？ |
| 阿拉伯文 | madhhab／firqa | 行走的方式／分裂 | 方法不同，還是信仰不同？ |
| 梵文 | sampradāya | 傳承 | 誰把它交到你手上？ |

三個要點：①**漢語的「宗派」本身就是譜系學的詞**（源自佛教法脈），這對本書有利也
危險——中文讀者會以為譜系是理所當然的看法，而忘記它在西方語境裡是要論證的立場。
②**阿拉伯語用兩個詞區分「方法不同」與「信仰不同」，歐洲語言與漢語都沒有這個區分。**
③αἵρεσις 從「選擇」貶義化為「異端」，本身就記錄了一次判準的建立——語義史是制度史的
沉積層。

⚠️ 翻譯時要記得：英文研究說某教會是 denomination（問命名），漢譯成「宗派」讀者收到
的是血脈。**翻譯在這裡不只是換詞，是換了問題。**

## 建置

```bash
python scripts/christian_genealogy_build.py           # 連線抓原稿後建置
python scripts/christian_genealogy_build.py --cache   # 用 output/christian-genealogy/source.json 重建
python scripts/christian_genealogy_build.py --check   # 只驗算不寫檔
```

目錄在 `scripts/christian_genealogy_plan.py`（全書唯一的目錄來源）。輸出單一檔
`public/content/works/christian-genealogy/CG.html` 與同層的
`christian-genealogy-books.json`。idempotent，雜誌那邊改稿之後重跑即可同步。

**改寫單位是「節」不是章。** 寫好一節就放一個 `chapters-cN/sNN.html`（內容從 `<h3>`
起，章內小標用 `<h4>`）。**一章的節全部寫完才換上改寫稿**，否則仍出雜誌原稿——半新半舊
會讀起來像同一章有兩個作者。第1章沒有原稿，所以寫幾節出幾節。

**註號不必人工維護。** 節檔裡的 id 只要全書唯一即可（`fn-c1-a` 這種也行），組裝時按
出現順序全書重編並補回鏈。曾經人工編號而在兩節之間撞號，頁面看起來完全正常。

## 看起來成功的失敗

* **註釋清單可以編號正確而順序錯亂。** 節檔裡的條目順序是書寫順序，正文改過一輪、
  某條註被搬到別段之後就與引用順序錯開；連號、回鏈、三方對齊全部照樣通過，只有註釋
  清單變成 1、2、8、5、6⋯⋯，要一條一條看才發現。`build.py` 的 `sort_fn_items()`
  已在連號後補排序。
* **抓註釋區塊不能用正則前瞻。** 為了排序寫過
  `<div class="footnotes">(.*?)</div>\s*(?=<h3|<h2|</section)`，結果吃掉了整個第2章，
  而建置腳本仍回報「6/6 章 OK」——章數是照計畫數的，不是照產物數的。要用 div 深度掃。
* **網站的樣板會讓檢索看起來正常而全是假命中。** 洛桑那批每頁都有同一段導覽列
  （裡面就寫著四份基礎文件的名字），不剝的話查「Lausanne Covenant」會命中全部 109 篇。
  `genealogy_lausanne_fetch.py` 的 `strip_boilerplate()` 用行頻率（出現在六成以上檔案
  的短行）判樣板，比猜頭尾標記穩。

* **第6章看起來有八節，其實只有兩節有肉。** 節數與別章相當，字數卻只有三分之一。用
  節數判斷完成度會誤判——看每節字數。
* **雜誌原稿的圖有十一張是佔位符。** 第10期那篇的 `[[圖片N]]` 在 DB 裡沒有對應的
  `media_data`，Drive 第10期圖片夾也沒有 `10-14-*`。改寫稿不引原稿的 figure，所以這
  十一張已隨改寫一併消失；⚠️ 成書若要配圖，那十一處的圖說仍留在雜誌原稿裡，可從 DB
  取回。**日後若再從原稿建置，腳本會把圖說標成「［圖待製］」而版面看起來完全正常。**
* **註腳可以「數量對、內容錯」。** 原稿在雜誌那邊改動後若編號沒跟著調整，腳本仍會照號
  分配，結果是每條註都掛得上、但掛錯地方。改過稿就抽查中間幾節，別只看頭尾。
* **標「雜誌原稿」的章讀起來跟成書沒兩樣。** 章首的 `chapter-source` 那行有寫明「尚未
  為成書改寫」，但正文本身是完整的，很容易被當成已完成。
* **標籤可以壞掉而畫面完全正常。** 章降節那次遷移把每個節標題寫成 `<h3>…</h4>`，
  九處全錯，瀏覽器自動修正所以看不出來——是側邊欄節數多了一個才露餡。批次改標題層級
  之後要掃一次開閉標籤是否配對，規則是每個節檔第一個標題為 h3、其餘一律 h4。
* **結構改動會留下互指的殘骸。** 章節重編之後，內文的「第N章」「本卷」「卷三」全都會
  指錯，而頁面完全正常。改結構後必掃一次交叉引用；⚠️ 掃的時候要保護聖經章節
  （《使徒行傳》第六章這種）。
