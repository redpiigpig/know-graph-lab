# 基督宗教譜系學（/works/christian-genealogy）

把《無境界者》連載的五篇〈基督宗教譜系學〉重寫成一本書。全書問同一件事：**基督宗教
今天這些彼此不認識的分支，是怎麼一層一層分出來的？**

## 🟢 狀態（2026-09-09）

**一本書、六章。** 使用者 2026-09-09 定調：先前做成「五卷五十八章」是把一本書撐成一套
叢書，改回一章方法論＋五章五個時期。

| 章 | 時期 | 底本 | 狀態 |
|---|---|---|---|
| 1 譜系學作為方法 | — | 新寫 | ✅ 九節完成，約 1.9 萬字 |
| 2 從使徒到大公 | 起源事件之後 | 第12期 | ✅ 十一節完成，約 2.1 萬字 |
| 3 正統的劃界 | 正統化事件 | 第5期 | ✅ 七節完成，約 1.2 萬字 |
| 4 教系的成形 | 正統化事件的展開 | 第7期 | 雜誌原稿 |
| 5 宗派的裂變 | 改教事件之後 | 第10期 | 雜誌原稿．11 張圖未產 |
| 6 從宗派到陣營 | 現代化事件之後 | 第11期 | 雜誌原稿．篇幅只有別章 1/3 |

全書正文 8.5 萬字＋註 1.5 萬字、108 條註、56 節。第1至3 章已是成書稿。

## 🚨 事件四個，時期四個，章五章

第二個時期佔兩章：尼西亞先**劃界**（第3章），那條界再在往後五百年**分流**成七個教系
（第4章）。劃界是事件的直接後果，分流是它的展開。使用者一度問「還是四個時期？」——
時期確實是四個，別把章數當時期數，也別為了對齊而把第3、4 章併成一章。

## 🚨 核心主張：每次事件之後，譜系單位就換一次

這是全書的骨幹，也是它與孔漢思典範論的差別所在。

| 事件 | 此後判斷「一支」的依據 | 譜系單位 |
|---|---|---|
| 起源 | 保存誰的記憶、經誰傳下 | 記憶的保存者（軌跡） |
| 正統化 | 屬哪個教座、認哪份信經、用哪種神聖語言 | 教座與宗主教集團（教系） |
| 改教 | 認信哪份文書、追溯哪位會祖 | 認信文書＋會祖（宗派） |
| 現代化 | 站哪個立場、參與哪個運動 | 立場與運動（陣營） |

**用後一段的單位讀前一段，會錯得很像對的**：用宗派讀二世紀是時代錯置；用教座讀十六
世紀之後會得出「新教沒有教會」；用宗派讀二十世紀會完全看不見福音派與普世運動。每一
章開頭都要重述該章所用的單位。

跨宗教適用時，四類事件（起源／正統化／改革／現代化）是通用的，差別在三個變項：
**位置、強度、內生或外生**。佛教不是模型的反例，是正統化事件弱且改革事件緊貼起源
事件；印度教的現代化事件回過頭去製造了起源事件的敘述。

## 🚨 方法論的立場：不是分工，是同一個動作

早期版本把紐曼與傅柯寫成分工（傅柯管描述、紐曼管評價），被使用者退回——那等於預設
解構與建構必須分屬兩人兩階段。

正確的立場是**把正統／異端從判準降格為現象**：這一步同時解構（正統失去不被觀察的
特權）與建構（多出「邊界的生成史」這個正面的研究對象）。文獻護欄是威廉斯的**肯定性
譜系**（vindicatory genealogy，指出一個東西有出身不等於指出它是假的）與庫普曼把傅柯式
批判理解為**問題化**（並論證它與規範性重建不衝突）。

## 🚨 這套方法不是原創，書裡要照實寫

使用者直接問過。四項核心工具都有明確前人：

* **典範分期**——孔漢思《基督宗教：本質、歷史與未來》用孔恩的典範論切六個宏觀典範
  （尼西亞、改教、啟蒙都切了）；博許《更新變化的宣教》把它用在宣教史，是這套框架在
  華語神學教育的主要流通管道。
* **軌跡**——羅賓遜與克斯特《穿越早期基督教的軌跡》（1971）；上游是包爾（1934）。
  ⚠️ 本書只採包爾命題的弱版本（正統化之前多條軌跡並存），不採強版本（異端在許多地區
  是原初形態）；混用兩者是這個領域最常見的失誤。
* **譜系學進宗教研究**——阿薩德《宗教的譜系》（1993），但他做的是「宗教」這個範疇的
  譜系，不是宗派的譜系。
* **宗派按家族分類**——梅爾頓《美國宗教百科全書》自 1979 年起的標準作法。

剩下能主張的只有三點：把四者接成一張圖並指出接縫、把東方諸教會平等放進來、華語世界
空白。**不可以把「宗派譜系學」講成一門新學科。**

## 🚨 底本層的三個坑

1. **第6章的底本（11-6）在 DB 裡副標誤植為「初探（五）」。** 沒有第五篇，使用者
   2026-09-08 確認 11-6 就是最後一篇。別照 DB 的副標排序。
2. **章序不是刊登序。** 刊登序是 5→7→(8)→10→11→12，書序是 12、5、7、10、11——
   第2章的底本最晚寫卻擺最前。看到期號大的排前面不要「順手修正」。
3. **番外篇不收。** 第8期〈主教制的歷史演變與教會的大公性〉是同一系列，但使用者明確
   表示不收入本書。它仍留在雜誌那邊。

## 正本在哪裡

**無境界者網站的 Supabase `articles` 表**（`C:/Users/user/Desktop/nonchurch-nuxt/.env`
的 `VITE_SUPABASE_URL` + `SUPABASE_SECRET_KEY`），欄位 `content`（乾淨 HTML，`<h3>`
就是節）與 `footnotes`（`[{id, text}]`）。

**不要走 Drive 的 docx。** `G:/我的雲端硬碟/資料/無境界者/雜誌/*/` 那份是雜誌排版稿，
正文混著圖框錨點（`-381019494500`、`center30099000`、`right0在傳統教會的觀念中…`），
標題只能靠「粗體 + 14pt」猜，註腳要自己從 `word/footnotes.xml` 挖並對回
`w:footnoteReference`。而且第 2、5、6 章的底本（第 12、10、11 期）**根本沒有 docx**，
只存在於 DB。

## 建置

```bash
python scripts/christian_genealogy_build.py           # 連線抓原稿後建置
python scripts/christian_genealogy_build.py --cache   # 用 output/christian-genealogy/source.json 重建
python scripts/christian_genealogy_build.py --check   # 只驗算不寫檔
```

目錄在 `scripts/christian_genealogy_plan.py`（全書唯一的目錄來源）。輸出單一檔
`public/content/works/christian-genealogy/CG.html` 與同層的
`christian-genealogy-books.json`。idempotent，雜誌那邊改稿之後重跑即可同步。

**改寫單位是「節」不是章。** 寫好一節就放一個 `chapters-cN/sNN.html`（內容從 `<h3>`
起，章內小標用 `<h4>`）。**一章的節全部寫完才換上改寫稿**，否則仍出雜誌原稿——半新半舊
會讀起來像同一章有兩個作者。第1章沒有原稿，所以寫幾節出幾節。

**註號不必人工維護。** 節檔裡的 id 只要全書唯一即可（`fn-c1-a` 這種也行），組裝時按
出現順序全書重編並補回鏈。曾經人工編號而在兩節之間撞號，頁面看起來完全正常。

Schaff 那幾卷分段細，頁碼可用。

## 研究底稿

**館藏已有**（可全文檢索）：岡薩雷斯《基督教史》、《劍橋基督教史》九卷、畢爾麥爾三冊
教會史、優西比烏《教會史》、Schaff《七次大公會議》與《Creeds of Christendom》三卷、
《歷代信經信條》、莫菲特《亞洲基督教史》I/II（東方諸教會唯一紮實的中文材料）、麥格夫
《宗教改革運動思潮》、《新教百科全書》、《梵二文獻》、劉義《全球靈恩運動》。

**缺口很一致——理論骨架與普世運動那一段近乎空白**，已建
`data/zlib-wanted/denominational-genealogy.jsonl`（41 筆，走 [[ebook-zlib-harvest]]；⚠️ 多數著作的中譯有無尚未確認，已同時放中文書名與原文查詢讓每日排程實測）：

* 分化理論：紐曼《論基督教教義的發展》（**書裡引了但書不在館內**）、特爾慈、理查‧
  尼布爾《宗派主義的社會來源》、威廉斯《真理與真誠》、庫普曼《作為批判的譜系學》。
* 普世運動：Rouse & Neill《普世運動史》、BEM 利瑪文件、《稱義教義聯合聲明》、《波爾武
  共同聲明》。第6章第三節整節靠這批文件。
* 福音派與靈恩：貝賓頓、安德森、詹金斯。
* 東方教會：Brock、Baum & Winkler、Chaillot。第4章的第 3-6 支中文二手材料極少，這塊
  是全書最可能被指「西方中心」的位置。

## 還沒做的事

1. **第4至6章共 29 節尚未改寫。**
2. **第6章篇幅只有別章的三分之一**，而它站在全書結論的位置。
3. **術語全書統一。** 第4章把「教系／宗派／宗座／牧首」定義得很清楚，第5、6 章的原稿
   混用了「教派」「系統」「陣營」「共同體」。
4. **譯名跑一次《翻譯定名》詞庫。** 宗教改革以後的新教人物（施本爾、親岑多夫、
   懷特菲爾德、愛德華茲⋯⋯）詞庫多半還沒有條目，要先立條再回頭改稿。
5. **圖。** 28 張圖多為生成圖，第5章另有 11 張未產；送印須重製為向量圖。

## 看起來成功的失敗

* **第6章看起來有八節，其實只有兩節有肉。** 節數與別章相當，字數卻只有三分之一。用
  節數判斷完成度會誤判——看每節字數。
* **第5章印出來一切正常，但十一張圖不見了。** 佔位符 `[[圖片N]]` 在 DB 裡沒有對應的
  `media_data`，Drive 第10期圖片夾也沒有 `10-14-*`。腳本把圖說標成「［圖待製］」，
  版面看起來完全正常。
* **註腳可以「數量對、內容錯」。** 原稿在雜誌那邊改動後若編號沒跟著調整，腳本仍會照號
  分配，結果是每條註都掛得上、但掛錯地方。改過稿就抽查中間幾節，別只看頭尾。
* **標「雜誌原稿」的章讀起來跟成書沒兩樣。** 章首的 `chapter-source` 那行有寫明「尚未
  為成書改寫」，但正文本身是完整的，很容易被當成已完成。
* **標籤可以壞掉而畫面完全正常。** 章降節那次遷移把每個節標題寫成 `<h3>…</h4>`，
  九處全錯，瀏覽器自動修正所以看不出來——是側邊欄節數多了一個才露餡。批次改標題層級
  之後要掃一次開閉標籤是否配對，規則是每個節檔第一個標題為 h3、其餘一律 h4。
* **結構改動會留下互指的殘骸。** 章節重編之後，內文的「第N章」「本卷」「卷三」全都會
  指錯，而頁面完全正常。改結構後必掃一次交叉引用；⚠️ 掃的時候要保護聖經章節
  （《使徒行傳》第六章這種）。
