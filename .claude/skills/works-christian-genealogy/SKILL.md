# 基督宗教譜系學（/works/christian-genealogy）

把《無境界者》連載的〈基督宗教譜系學〉五卷合成一本書。全書問同一件事：**基督宗教今天
這些彼此不認識的分支，是怎麼一層一層分出來的？** 方法上借紐曼《論基督教教義的發展》的
有機體比喻——分化不是墮落，是信仰適應環境留下的痕跡。

骨架是卷一提出的**分化四階段**：正統的劃界 → 教系的成形 → 宗派的裂變 → 近現代的聯盟。
卷〇是最後才補寫的前史，把起點從尼西亞往前推到使徒見證網絡。

## 🚨 卷號的坑

1. **卷四在 DB 裡的副標寫的是「初探（五）」。** 沒有第五卷，也沒有另一篇卷四——使用者
   2026-09-08 確認 11-6 就是卷四。書稿依此定序，別照 DB 的副標排。
2. **卷序不是刊登序。** 刊登序是 5→7→(8)→10→11→12，書序是 〇一二三四，卷〇最晚寫但擺
   最前。看到期號大的排前面不要「順手修正」。
3. **番外篇不收。** 第8期〈主教制的歷史演變與教會的大公性〉是同一系列，但使用者明確表示
   不收入本書。它仍留在雜誌那邊。

## 正本在哪裡

**無境界者網站的 Supabase `articles` 表**（`C:/Users/user/Desktop/nonchurch-nuxt/.env`
的 `VITE_SUPABASE_URL` + `SUPABASE_SECRET_KEY`），欄位 `content`（乾淨 HTML）與
`footnotes`（`[{id, text}]`）。

**不要走 Drive 的 docx。** `G:/我的雲端硬碟/資料/無境界者/雜誌/*/` 那份是雜誌排版稿，
正文裡混著圖框錨點（`-381019494500`、`center30099000`、`right0在傳統教會的觀念中…`），
標題只能靠「粗體 + 14pt」判斷，註腳要自己從 `word/footnotes.xml` 挖並對回 `w:footnoteReference`。
DB 那份全部免了。而且卷三、卷四、卷〇根本沒有 docx——第10-12 期的稿只在 DB 裡。

## 建置

```bash
python scripts/christian_genealogy_build.py           # 連線抓取後建置
python scripts/christian_genealogy_build.py --cache   # 用 output/christian-genealogy/source.json 重建
python scripts/christian_genealogy_build.py --check   # 只驗算不寫檔
```

輸出 `public/content/works/christian-genealogy/G0…G4.html` 與同層的
`christian-genealogy-books.json`。idempotent，雜誌那邊改稿之後重跑即可同步。

腳本做四件事：`<h3>` 節標題 → `<h2>` 章標題並包成 `<section class="chapter">`；註號重新
掛錨（`#footnote-N` → `#fn-g3-N`）並把註文按「這一章引到誰」分配到章末；未產圖的
`[[圖片N]]` 佔位符拿掉 `<img>` 但保留圖說並標「［圖待製］」；卷首補 `book-head`。

`--check` 會報出四種異常：缺註文、孤兒註（有註文沒人引）、斷鏈、未產的圖。**正常輸出是
五行 OK，任何一行 WARN 都不要當成小事**——註腳對不上通常代表原稿被改過而編號沒跟著動。

## 成書要做的六件事

1. **卷四要補足。** 它承擔全書結論的位置，卻只有 0.8 萬字。九章裡「五種分類層級」與
   「三層譜系模型」是骨架，天主教／東正教／東方諸教會三章只到提綱程度。
2. **卷〇與卷一的前言重疊。** 卷一的〈前言：為什麼我們需要宗派譜系學？〉與〈宗教內部
   分化的四個階段〉其實是全書導論，寫在卷一等於把導論埋在第二卷。成書時上移為導論，
   卷一改從「正統化之前的諸基督教時代」起講。
3. **四階段模型要接受檢驗。** 模型宣稱可用於「大多數宗教」，書裡卻只用基督宗教證明。
   至少拿伊斯蘭（吻合度高）與佛教（明顯吃力：部派分裂早於語系分流，且從無帝國尺度的
   統一權威）各試一次，並把適用條件寫在明處。這是全書最容易被攻擊的一點。
4. **術語全書統一。** 卷二把「教系（religious branch）／宗派（denomination）／宗座
   （The Apostolic See）／牧首（Supreme Patriarch）」定義得很清楚，卷三卷四混用了
   「教派」「系統」「陣營」「共同體」。
5. **譯名跑一次《翻譯定名》詞庫。** 宗教改革以後的新教人物（施本爾、親岑多夫、
   懷特菲爾德、愛德華茲⋯⋯）詞庫多半還沒有條目，要先立條再回頭改稿。
6. **圖。** 28 張圖多半是 ChatGPT／Gemini 生成的示意圖，卷三另有 11 張沒產。要送印就得
   重製為向量圖，並處理生成圖的標示問題。

## 研究底稿

**館藏已有**（可全文檢索）：岡薩雷斯《基督教史》、《劍橋基督教史》九卷、畢爾麥爾三冊
教會史、優西比烏《教會史》、Schaff《七次大公會議》與《前尼西亞教父》、《歷代信經信條》、
莫菲特《亞洲基督教史》I/II（東方諸教會唯一紮實的中文材料）、麥格夫《宗教改革運動思潮》、
《新教百科全書》、Schaff《Creeds of Christendom Vol.3》、《梵二文獻》、劉義《全球靈恩運動》。

**缺口很一致——理論骨架與普世運動那一段近乎空白**，已建
`data/zlib-wanted/denominational-genealogy.jsonl`（26 筆，走 [[ebook-zlib-harvest]]）：

* 分化理論：紐曼《論基督教教義的發展》（**卷一正文引了但書不在館內**）、特爾慈、理查‧
  尼布爾《宗派主義的社會來源》。卷三談「新教為何持續裂變」不接上這一支就只能停在描述層。
* 普世運動：Rouse & Neill《普世運動史》、BEM 利瑪文件、《稱義教義聯合聲明》、《波爾武
  共同聲明》。卷四第五章整章靠這批文件。
* 福音派與靈恩：貝賓頓、安德森、詹金斯。
* 東方教會：Brock、Baum & Winkler、Chaillot。卷二的第 3-6 個大公傳統中文二手材料極少，
  這塊是全書最可能被指「西方中心」的位置。

## 看起來成功的失敗

* **卷四看起來有九章，其實只有兩章有肉。** 章數與別卷相當，字數卻只有三分之一。用章數
  判斷完成度會誤判——看每章字數。
* **卷三印出來一切正常，但十一張圖不見了。** 佔位符 `[[圖片N]]` 在 DB 裡沒對應的
  `media_data`，Drive 第10期圖片夾也沒有 `10-14-*`。腳本會把圖說標成「［圖待製］」，
  但版面看起來完全正常。
* **註腳可以「數量對、內容錯」。** 原稿在雜誌那邊改動之後，若編號沒跟著調整，腳本仍會
  照號分配，結果是每條註都掛得上、但掛錯地方。改過稿就抽查中間那幾章，別只看頭尾。
* **書稿頁的五卷是原稿轉錄，一字未改。** 別把它當成「已經是書」——`book-meta` 那行有寫
  明「尚未為成書改寫」，但頁面讀起來跟成書沒兩樣。
