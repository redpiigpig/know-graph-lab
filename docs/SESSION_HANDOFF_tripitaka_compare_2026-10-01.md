## 一部（一品）的做法 — 照金剛經、維摩詰第一品的範本

1. 印出各本該段全文：
   - 漢文：`tripitaka_compare_auto.zh_chapters(work)`（品）或 `zh_body(work, node)`
   - 梵本：`sa_chapters('T0475')`（按品），或 GRETIL 直取 `src: {"gretil": "<檔名>"}`
     （檔名查 `C:/tmp/cbeta/gretil/_index.html` 的 `gretil/corpustei/sa_*.xml`）
   - 藏英：`tmx_units('toh176','en')` 看英譯定界；品界 `tei_chapter_starts('toh176', en)`
     （維摩詰品首：0, 243, 344, … 第 2 品 = 243 起）
2. 以梵本自帶的段號／節號當骨架（Vkn 品.段、Vaidya §、穆勒 //n//），十來到二十幾個義段一品。
3. **讀過每一本**，在 `scripts/tripitaka_compare.py` 的 `SETS` 寫切點：
   漢文用「從哪幾個字起」、藏英用 TMX 句號（兩欄同一組句號）。維摩詰用 `_vkn_versions()`。
4. `python -X utf8 scripts/tripitaka_compare.py <slug>` —— 三道閘：切點找不到整組拒絕／
   切完接回須與原文逐字相符／義段不重複且照序（原典確實換位才設 `reorder`）。
5. 抽查 4–6 節：`node -e` 印 `cells[u]` 各本開頭，**看人名是否對上**。
6. 只 `git add` 自己動到的檔；`git pull --rebase --autostash` 再 push；push 後
   `git log origin/master | grep` 確認提交在遠端（多 session 同時推，push 常報錯但已被別人帶上去）。
7. 更新 `.claude/skills/scripture-tripitaka/SKILL.md` 的「異譯對讀」表。
